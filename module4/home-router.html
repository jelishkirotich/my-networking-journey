MODULE 4

Home Router

Understanding the parts of a home router, its ports, wireless functions, and how it connects a home network to the Internet.

Introduction

A router is one of the most important devices in a typical home network. It connects the local home network to other networks, including the Internet.

A modern home router can perform several functions at the same time. It can provide wired Ethernet connections, Wi-Fi connectivity, DHCP services, and routing between the local network and the Internet.

In this topic, we will identify the main parts of a home router and understand what each part does.

1. What Is a Router?

A router is a networking device that connects different networks and forwards data between them.

In a home network, the router normally connects the private local network inside the house to the ISP's network.

A typical home router can provide both wired and wireless network connectivity.

Simple Idea

Think of the router as the device that connects your home network to other networks and decides where network traffic should go.

2. The Main Parts of a Home Router

Although routers can look different depending on the manufacturer and model, many home routers have similar parts.

  • WAN or Internet port
  • LAN Ethernet ports
  • Wireless antennas
  • Power connection
  • Reset button
  • Status lights

Some routers also include additional features such as USB ports, telephone ports, or combined modem functions.

3. WAN or Internet Port

WAN stands for Wide Area Network. The WAN port is normally used to connect the router to the device or connection that provides Internet access.

Depending on the type of service, the WAN port may be connected to a modem, an ONT, or another upstream network device.

The WAN or Internet port connects the router toward the ISP or upstream network.

Remember

The WAN side faces the external network, while the LAN side is used for devices inside the local network.

4. LAN Ethernet Ports

LAN stands for Local Area Network. The LAN ports are used to connect wired devices inside the home network.

For example, you could connect a desktop computer, printer, game console, smart television, or another network device to a LAN port using an Ethernet cable.

LAN ports allow wired devices to join the local network.

5. WAN vs LAN Ports

WAN / Internet Port LAN Ports
Connects toward the ISP or upstream network Connect devices inside the local network
Represents the external side of the router Represents the internal side of the router
Usually one main port Usually several Ethernet ports

Easy Way to Remember

WAN = outside

LAN = inside

6. Wireless Antennas

Many home routers have one or more antennas. These antennas are used to transmit and receive wireless radio signals.

Wireless devices such as smartphones, laptops, tablets, and smart televisions can connect to the router using Wi-Fi instead of an Ethernet cable.

Router antennas help provide wireless coverage for nearby devices.

7. Power Connection

A router needs electrical power to operate. Most home routers use an external power adapter.

Without power, the router cannot provide wired or wireless network connectivity.

8. Status Lights

Routers normally have indicator lights that provide information about the status of different connections.

Common Indicators

  • Power
  • Internet or WAN
  • LAN Ethernet
  • Wi-Fi
  • WPS on some routers

The exact meaning of each light depends on the router manufacturer and model.

9. Router and Modem Are Not the Same Thing

A router and a modem perform different networking functions, even though many devices supplied for home Internet service combine them into one physical box.

Router Modem
Connects different networks Provides the interface to certain ISP access technologies
Forwards traffic between networks Communicates over the service connection
Can provide LAN and Wi-Fi connectivity Connects to the ISP service

Modern Home Equipment

Many ISP devices combine a modem, router, Ethernet switch, and wireless access point into a single device. This is why people sometimes use the words "router" and "modem" as if they mean the same thing.

10. DHCP

DHCP stands for Dynamic Host Configuration Protocol. It can automatically provide devices with network configuration information.

In a typical home network, the router commonly acts as a DHCP server.

When a laptop or smartphone joins the home network, the router can automatically assign it an IP address and provide other configuration information.

Without DHCP

You would have to manually configure network information on every device.

With DHCP

The router can automatically provide the necessary network configuration to devices.

11. NAT

NAT stands for Network Address Translation. It allows a router to translate between addresses used on the private local network and the addressing used toward the external network.

This allows multiple devices in a home network to share an Internet connection using a single public IPv4 address in many common home setups.

NAT is commonly used by home routers between the private LAN and the external network.

12. How Devices Connect to the Router

Devices can normally connect to a home router in two main ways.

Wired Connection

A device is connected to one of the router's LAN Ethernet ports using a network cable.

Wireless Connection

A device connects to the router through Wi-Fi using the network's SSID and wireless security settings.

13. A Simple Home Router Setup

A simple home network can look like this:

Internet → WAN Port → Router → LAN Ports / Wi-Fi → Devices

The WAN connection leads toward the ISP. The router then provides network connectivity to devices inside the home.

14. What We Need to Remember

  • A router connects different networks.
  • The WAN port connects toward the ISP or upstream network.
  • LAN ports connect devices inside the local network.
  • Wi-Fi allows devices to connect without an Ethernet cable.
  • DHCP can automatically assign IP configuration to devices.
  • NAT is commonly used between a private home network and the external network.
  • A modem and router perform different functions.
  • Some modern home devices combine modem and router functions.
