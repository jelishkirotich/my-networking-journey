MODULE 4

Wireless Router Configuration

Learning how to access a wireless router, configure basic settings, create a Wi-Fi network, and connect devices.

Introduction

A wireless router normally comes with a configuration interface that allows an administrator to change its settings.

Many home routers provide a web-based graphical interface that can be accessed using a web browser. The exact appearance and menu names depend on the manufacturer and router model.

In this topic, we will go through the basic process of connecting a computer to a router, opening the router's configuration page, changing wireless settings, and connecting a device to the resulting Wi-Fi network.

1. What Do We Need?

Before configuring a wireless router, we need a few basic things.

  • A wireless router
  • A computer or laptop
  • An Ethernet cable
  • Power for the router
  • A web browser
  • The router's login information

For initial configuration, using an Ethernet cable is useful because it gives us a direct connection to the router without depending on the wireless settings that we are about to configure.

2. Connect the Computer to the Router

First, connect the computer to one of the router's LAN Ethernet ports.

The computer can be connected to a LAN port using an Ethernet cable.

Step 1

Connect one end of the Ethernet cable to the computer's Ethernet port.

Step 2

Connect the other end of the cable to one of the router's LAN ports.

Step 3

Turn on the router and wait for it to finish starting.

3. Why Use a LAN Port?

The router normally has a WAN or Internet port and one or more LAN ports.

During local configuration, the computer should normally be connected to a LAN port because we are accessing the router from inside the local network.

Remember

WAN is normally used toward the external or ISP network.

LAN is used for devices inside the local network.

4. Find the Router's IP Address

The router normally has a local IP address that can be used to access its configuration interface.

Common router addresses include addresses such as 192.168.0.1 or 192.168.1.1, but the actual address depends on the router.

You should use the address provided by the router's manufacturer or ISP rather than assuming that every router uses the same address.

Example

If your router uses:

192.168.1.1

that address can be entered into the browser's address bar to reach the router's configuration page.

5. Open the Router's Web Interface

Open a web browser on the connected computer.

Step 1

Open a browser such as Chrome, Edge, Firefox, or another browser.

Step 2

Click the address bar at the top of the browser.

Step 3

Enter the router's local management address.

Example: 192.168.1.1

Step 4

Press Enter.

A router may display a login page before allowing access to its configuration settings.

6. Log In to the Router

The router may require an administrator username and password before allowing configuration changes.

The login details depend on the router. They may be printed on the router, supplied by the ISP, or created during the initial setup.

Security Reminder

Do not leave the router using an easily guessed administrator password. The administrator password controls access to the router's configuration.

7. Find the Wireless Settings

After logging in, look for a section named something similar to:

  • Wireless
  • Wi-Fi
  • Wireless Settings
  • Wireless Setup
  • WLAN

The exact name depends on the router manufacturer.

A router's wireless configuration page may contain settings for the SSID, channel, wireless mode, security, and other options.

8. Configure the SSID

The first setting we can configure is the SSID, which is the name of the wireless network.

Example

Suppose we want our home network to appear as:

MyHomeWiFi

We would enter that name in the SSID field.

After saving the setting, nearby devices may see MyHomeWiFi in their list of available wireless networks.

9. Choose the Wireless Mode

The wireless mode determines which supported wireless standards the router can use.

Depending on the router, you may see options such as a specific 802.11 standard or a mixed mode.

Mixed Mode

Mixed mode allows compatible devices using different generations of wireless technology to connect to the same wireless network.

10. Choose a Wireless Channel

The wireless settings may also contain a channel option.

You may be able to choose a specific channel or allow the router to select a channel automatically.

For a Beginner

If you are not troubleshooting a wireless problem, leaving channel selection on Auto is often the simplest starting point.

11. Configure Wireless Security

A wireless network should normally use appropriate security rather than leaving the network open.

Modern equipment may provide WPA2-Personal, WPA3-Personal, or a WPA2/WPA3 transition option depending on the router and the devices that need to connect. Cisco documentation describes WPA2/WPA3 mixed configurations for compatible clients.

Wireless Password

The wireless password is used by clients when they join the secured Wi-Fi network.

Use a strong password rather than something that is easy for other people to guess.

Do Not Confuse These Passwords

The router administrator password protects access to the router's configuration.

The Wi-Fi password allows devices to join the wireless network.

They perform different jobs.

12. SSID Broadcast

The wireless configuration may also contain an SSID Broadcast option.

When enabled, the wireless network is normally advertised so that nearby devices can see its name in their Wi-Fi list.

If disabled, the network may not appear in the normal list and a user may need to enter the network name manually.

Security Reminder

Disabling SSID broadcast does not make a wireless network secure by itself. Proper wireless encryption and a strong password are much more important.

13. Save the Configuration

After changing the settings, look for a button such as:

  • Save
  • Apply
  • Save Changes
  • Apply Settings

The router may restart its wireless service after the settings are applied.

Important

If you change the SSID or wireless password while connected through Wi-Fi, your wireless connection may be disconnected. This is another reason why using an Ethernet connection during initial configuration can be useful.

14. Connect a Device to the New Wi-Fi Network

Once the router has been configured, we can connect another device such as a smartphone or laptop.

Step 1

Open the Wi-Fi settings on the device.

Step 2

Find the SSID that was configured on the router.

Step 3

Select the network.

Step 4

Enter the wireless password.

Step 5

Wait for the device to connect.

A wireless client can connect to the configured SSID using the correct security credentials.

15. Check the Connection

After connecting the device, we can test whether the network is working.

Check 1: Wi-Fi Connection

Confirm that the device shows that it is connected to the correct wireless network.

Check 2: IP Address

Check that the device received an IP address from the router.

Check 3: Router Connectivity

Test whether the device can communicate with the local router.

Check 4: Internet Connectivity

If the router has a working Internet connection, test whether the device can reach an Internet service.

16. Basic Configuration Summary

The basic configuration process can be summarized as:

Computer → Ethernet → LAN Port → Router GUI

Router GUI → SSID → Wireless Mode → Channel → Security

Save → Connect Device → Test Connection

17. What We Need to Remember

  • A router can be configured through a web-based interface.
  • A computer can be connected to a router through a LAN Ethernet port.
  • The router has a local management IP address.
  • The SSID is the name of the wireless network.
  • Wireless mode determines supported wireless standards.
  • The channel determines where the wireless network operates within its available spectrum.
  • Wireless security protects the network from unauthorized access.
  • The Wi-Fi password and administrator password have different purposes.
  • After configuration, wireless devices can connect using the SSID and correct credentials.
  • The connection should be tested after configuration.
