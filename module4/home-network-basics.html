Home Network Basics

1. What Is a Home Network?

A home network is a group of devices connected together within a home so that they can communicate with each other and share network resources. These devices may include computers, smartphones, tablets, printers, smart TVs, game consoles, and other smart devices.

A home network is a type of Local Area Network, commonly called a LAN. A LAN connects devices within a limited physical area such as a home, school, office, or building.

Simple idea:

A home network allows the devices in your home to communicate with each other and, through a router and an Internet connection, communicate with devices and services outside your home.

In a typical home, the router is an important central device. It can provide wired Ethernet connections and wireless Wi-Fi connections. Many modern home routers combine several networking functions into one device.

2. Components of a Home Network

A network needs different components to allow devices to connect, communicate, and access other networks. The exact equipment depends on the size and purpose of the network.

Router

A router connects different networks together. In a home, the router normally connects the local home network to the Internet. It can also provide services such as DHCP and Network Address Translation (NAT).

Switch

A switch connects multiple wired devices within the same local network. For example, a switch can connect computers, printers, servers, and access points using Ethernet cables.

Many home routers already contain a small Ethernet switch, which is why a typical home router may have several LAN Ethernet ports.

Wireless Access Point

A wireless access point, or WAP, allows wireless devices to connect to a network. It provides the wireless connection between devices such as laptops and smartphones and the rest of the network.

In a typical home, you may not see a separate access point because the wireless access point is built into the wireless router.

Modem or ONT

Depending on the type of Internet service, a home may use a modem or an Optical Network Terminal (ONT) to connect the home network to the Internet service provided by an ISP.

The exact equipment depends on the technology used by the Internet service provider. We will examine modems, DSL, cable connections, coaxial connections, and fiber connections in the next topics.

3. End Devices

End devices are the devices used by people or applications to send and receive information across a network. They are also commonly called hosts.

Examples of home network end devices include:

  • Desktop computers
  • Laptops
  • Smartphones
  • Tablets
  • Smart TVs
  • Game consoles
  • Network printers
  • Security cameras
  • Smart speakers
  • Other Internet of Things (IoT) devices
Remember:

A router, switch, or access point provides network connectivity, while an end device is usually the device that the user actually uses to send or receive data.

4. Wired and Wireless Connections

Devices can connect to a network using either a physical cable or a wireless connection.

Wired Connection

In a wired network, data travels through a physical cable. Ethernet connections commonly use twisted-pair copper cables, although Ethernet can also operate over fiber-optic media.

Example:

A desktop computer connected to a router using an Ethernet cable is using a wired network connection.

Wireless Connection

In a wireless network, devices communicate through radio signals instead of using a physical network cable for the connection between the device and the wireless access point.

Example:

When your phone connects to your home Wi-Fi without an Ethernet cable, it is using a wireless network connection.

Wi-Fi is based on the IEEE 802.11 family of wireless networking standards, while Ethernet is associated with IEEE 802.3.

5. Network Standards

Network standards are agreed rules and technical specifications that allow devices and networking equipment from different manufacturers to communicate correctly.

Without standards, devices made by different companies could have difficulty communicating with one another.

IEEE

The Institute of Electrical and Electronics Engineers (IEEE) develops and maintains many technical standards used in networking.

IEEE 802.3

IEEE 802.3 is associated with Ethernet networking. Ethernet is widely used for wired local area network connections.

IEEE 802.11

IEEE 802.11 is the family of standards used for Wi-Fi wireless networking. Different generations of Wi-Fi use different amendments and capabilities within the 802.11 family.

Important distinction:

IEEE 802.3 → Ethernet

IEEE 802.11 → Wi-Fi

6. Basic Network Security

Connecting devices to a network also means protecting that network. Network security involves protecting devices, information, and network resources from unauthorized access and other threats.

Use a Strong Wi-Fi Password

A wireless network should use a strong password rather than an easy password that other people could guess.

Use Modern Wireless Security

Modern Wi-Fi security mechanisms provide encryption and authentication so that unauthorized users cannot simply join the network or easily read wireless traffic.

We will examine wireless security settings in more detail when we configure the wireless router later in this module.

Change Default Router Credentials

A newly installed router may have default administrative credentials. These should be changed during setup so that someone who knows the manufacturer's default credentials cannot easily access the router's administration interface.

Keep Devices Updated

Router firmware, computers, phones, and other network-connected devices should be kept up to date. Updates can include security fixes and improvements.

Be Careful About Unknown Devices

It is useful to know which devices are connected to your home network. If an unfamiliar device appears in the router's connected-device list, it should be investigated.

Security awareness:

A network is not secure simply because it has Wi-Fi. Security depends on how the network and its devices are configured and maintained.
