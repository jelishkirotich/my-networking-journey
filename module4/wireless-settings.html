MODULE 4

Wireless Settings

Understanding Wi-Fi standards, SSIDs, wireless channels, mixed modes, channel width, and basic wireless settings.

Introduction

A wireless router does more than simply provide a Wi-Fi signal. It has several settings that control how wireless devices connect to the network.

When we open a router's wireless configuration page, we may see options such as wireless mode, SSID, channel, channel width, and SSID broadcast.

Understanding these settings helps us understand what is happening when a phone or laptop connects to Wi-Fi.

1. What Is Wi-Fi?

Wi-Fi is a wireless networking technology used to connect devices to a local network without using a physical Ethernet cable.

Wi-Fi is based on the IEEE 802.11 family of wireless networking standards.

A wireless router can provide Wi-Fi connectivity to nearby devices.

2. IEEE 802.11

IEEE 802.11 is a family of standards used for wireless local area networking.

Over time, different versions of the standard have been developed. These versions introduced improvements in areas such as speed, efficiency, frequency bands, and wireless capabilities.

Standard Common Wi-Fi Name General Idea
802.11b Wi-Fi 1 Older 2.4 GHz wireless technology
802.11g Wi-Fi 3 Improved 2.4 GHz wireless networking
802.11n Wi-Fi 4 Improved performance and support for 2.4 GHz and 5 GHz
802.11ac Wi-Fi 5 Primarily associated with higher-speed 5 GHz Wi-Fi
802.11ax Wi-Fi 6 / Wi-Fi 6E Improved efficiency and performance in busy networks

You do not need to memorize all of these standards at once. The important idea is that newer standards generally introduce improvements while modern routers may support several standards.

3. Wireless Mode

Wireless mode determines which wireless standards a router or access point will support.

Depending on the router, you may see settings such as 802.11n, 802.11ac, 802.11ax, or a mixed mode.

Example

If a router is configured to support multiple wireless standards, devices using different supported standards may be able to connect to the same wireless network.

4. Mixed Mode or Legacy Mode

Some routers provide a mixed or legacy mode that allows different generations of wireless clients to connect.

For example, a router may allow newer devices and older compatible devices to use the same wireless network.

Why Use Mixed Mode?

Mixed mode can be useful when a network contains devices that do not all support the same wireless standard.

However, supporting older technologies can sometimes introduce limitations compared with using a newer standard throughout the network.

5. SSID

SSID stands for Service Set Identifier.

The SSID is the name used to identify a wireless network. It is the name you normally see when you open the Wi-Fi list on your phone or laptop.

The names displayed in a Wi-Fi network list are examples of SSIDs.

Example

Suppose you name your home Wi-Fi:

Jelish Home WiFi

That name is the SSID of the wireless network.

6. SSID Broadcast

Wireless access points regularly transmit information that allows nearby wireless devices to discover available networks. The SSID is included in wireless network information advertised by the access point.

Most home routers have an option called SSID Broadcast.

SSID Broadcast Enabled

When SSID broadcast is enabled, the network normally appears in the Wi-Fi list of nearby devices.

SSID Broadcast Disabled

When the broadcast is disabled, the network name may not appear in the normal list of available Wi-Fi networks. A user may need to enter the network name manually.

Important Security Point

Hiding an SSID should not be treated as a strong security measure. The SSID can still be discovered through wireless communication.

7. Wireless Channels

A wireless channel is a portion of the radio spectrum used by a Wi-Fi network to communicate.

Wireless routers can use different channels depending on the frequency band and the regulatory rules in the region where the equipment is being used.

Wireless networks use channels within their available frequency bands.

8. Why Do Channels Matter?

Wi-Fi signals from nearby networks can interfere with each other when they use overlapping or heavily congested channels.

This is especially important in places where many homes, offices, or access points are close together.

In the 2.4 GHz band, channels 1, 6, and 11 are commonly used because they are separated so that they do not overlap with each other in the usual 20/22 MHz channel arrangements.

Simple Example

Imagine several houses next to each other. If all the routers are using the same congested channel, their wireless transmissions may compete for the same radio space.

9. Automatic Channel Selection

Many routers have an Auto option for the wireless channel.

When automatic channel selection is enabled, the wireless device can scan the available channels and choose one according to the router's channel-selection process.

Cisco documentation describes automatic channel selection as a process that can choose a channel based on detected traffic or congestion.

10. Channel Width

Channel width refers to how much radio spectrum a wireless transmission uses.

Common settings may include values such as 20 MHz, 40 MHz, or wider channels on newer Wi-Fi technologies.

Simple Idea

A wider channel can provide more capacity, but it also uses more of the available radio spectrum. In a crowded wireless environment, wider channels may encounter more competition from other networks.

11. Wireless Frequency Bands

Modern Wi-Fi equipment can operate on different frequency bands. Common home routers support 2.4 GHz and 5 GHz, while some newer equipment also supports 6 GHz.

Band General Characteristics
2.4 GHz Longer typical range and greater susceptibility to congestion from other devices.
5 GHz More available channels and generally less crowded than 2.4 GHz, but shorter typical range.
6 GHz Used by newer Wi-Fi generations and provides additional spectrum where supported.

The exact channels and frequencies available depend on the wireless standard, device, and regulatory requirements for the region.

12. Basic Wireless Settings Example

A typical home router's wireless settings might contain options similar to these:

Wireless Network Name

This is the SSID that users see when looking for available Wi-Fi networks.

Wireless Mode

Determines which supported wireless standards can be used.

Channel

Determines which wireless channel the network uses. Some routers can select this automatically.

Channel Width

Determines how much spectrum the wireless transmission uses.

SSID Broadcast

Determines whether the network name is advertised normally to nearby wireless devices.

13. What We Need to Remember

  • Wi-Fi is based on the IEEE 802.11 family of standards.
  • Wireless mode determines which standards a device supports.
  • Mixed or legacy modes can allow compatible older and newer devices to connect.
  • SSID means Service Set Identifier.
  • The SSID is the name used to identify a wireless network.
  • Wireless channels are portions of the radio spectrum used for communication.
  • Channel congestion and interference can affect wireless performance.
  • Channel width determines how much spectrum a transmission uses.
  • SSID broadcast controls whether the network is normally advertised to nearby devices.
  • Hiding an SSID is not a strong replacement for proper wireless security.
