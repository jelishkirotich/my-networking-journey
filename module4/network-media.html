Network Media and Connections

Understanding the different physical and wireless methods used to connect devices and carry data across a network.

Introduction

Network devices need a way to communicate with each other. The connection between devices can be made using physical cables or wireless technologies.

In this topic, we will look at common network media such as Ethernet cables, UTP, coaxial cable, and fiber-optic cable. We will also look at wireless connections such as Wi-Fi and Bluetooth.

1. What Is Network Media?

Network media refers to the path or method used to carry data from one device to another.

Network media can be divided into two main categories: wired media and wireless media.

Wired Media

Wired media uses a physical cable to carry data. Examples include UTP cable, coaxial cable, and fiber-optic cable.

Wireless Media

Wireless media allows devices to communicate without a physical cable. Examples include Wi-Fi, Bluetooth, and cellular networks.

2. Wired and Wireless Media

Wired connections usually provide a direct physical path between devices. Wireless connections use radio waves or other wireless signals instead of a physical cable.

Type Examples How Data Travels
Wired UTP, Coaxial, Fiber Through a physical cable
Wireless Wi-Fi, Bluetooth Through wireless signals

3. Ethernet

Ethernet is one of the most common technologies used for wired computer networks. It allows devices such as computers, switches, routers, and printers to communicate over a network.

Ethernet is associated with the IEEE 802.3 family of networking standards.

An Ethernet cable commonly uses an RJ45-style connector to connect a device to a network port.

Important Difference

Ethernet is the networking technology or standard. The cable used to carry Ethernet data can be made from different physical media, such as copper UTP cable or fiber-optic cable.

4. UTP Cable

UTP stands for Unshielded Twisted Pair. It is one of the most common types of copper cable used in Ethernet networks.

Inside the cable are pairs of copper wires twisted around each other. The twisting helps reduce interference between the wires.

UTP cable contains pairs of twisted copper wires.

Why Are the Wires Twisted?

Electrical signals travelling through copper wires can experience interference. Twisting the wires helps reduce the effects of electromagnetic interference and crosstalk.

Common Uses

  • Connecting computers to switches
  • Connecting computers to routers
  • Connecting access points
  • Connecting network devices in LANs

5. Coaxial Cable

Coaxial cable is another type of copper cable. It contains a central conductor surrounded by insulation and shielding.

A coaxial cable contains several layers that protect the signal travelling through the cable.

Coaxial cable is commonly used for cable television and cable Internet connections.

Coaxial Splitter

A coaxial splitter can divide a signal from one coaxial cable so that it can be sent to multiple connections. For example, a home may use a splitter when the same incoming coaxial connection is used for both television and cable Internet.

A coaxial splitter can divide an incoming coaxial connection into multiple outputs.

6. Fiber-Optic Cable

Fiber-optic cable uses light to transmit data instead of electrical signals travelling through copper wires.

Fiber-optic cables transmit information using light.

Fiber can support very high data rates and can carry signals over long distances. It is commonly used in Internet infrastructure and high-speed network connections.

Why Fiber Is Important

  • Uses light instead of electrical signals
  • Supports high-speed communication
  • Can cover long distances
  • Is not affected by electromagnetic interference in the same way as copper

7. Cable Categories

Ethernet copper cables are available in different categories. The category helps identify the capabilities of the cable.

Category General Use
Cat5e Common Ethernet networks and Gigabit Ethernet
Cat6 Higher-performance Ethernet installations
Cat6a Higher-speed installations and longer 10 Gigabit Ethernet runs

When choosing a cable, the cable category should match the network equipment and the required speed and distance.

8. Bluetooth and Other Wireless Connections

Wireless technologies allow devices to communicate without using a physical network cable.

Bluetooth

Bluetooth is a short-range wireless technology commonly used to connect devices such as phones, wireless headphones, keyboards, mice, speakers, and other peripherals.

Bluetooth can be used to connect nearby devices without a physical cable.

Wi-Fi

Wi-Fi is a wireless networking technology based on the IEEE 802.11 family of standards. It is commonly used to connect computers, smartphones, tablets, televisions, and other devices to a local network.

Bluetooth vs Wi-Fi

Bluetooth is mainly designed for short-range device-to-device connections, while Wi-Fi is commonly used to provide wireless network and Internet access.

9. Comparing Network Media

Media Type Main Characteristic Common Use
UTP Wired Copper twisted pairs Ethernet LANs
Coaxial Wired Shielded copper conductor Cable TV and Cable Internet
Fiber-optic Wired Uses light High-speed and long-distance networks
Wi-Fi Wireless Uses radio signals Wireless LANs
Bluetooth Wireless Short-range wireless communication Personal devices and peripherals

10. What We Need to Remember

Network media provides the path through which information travels between devices.

The main wired media we covered are UTP, coaxial cable, and fiber-optic cable. Wireless technologies include Wi-Fi and Bluetooth.

Key Points

  • Ethernet is a wired networking technology.
  • UTP is a copper physical cable used commonly with Ethernet.
  • Coaxial cable is used for applications such as cable TV and cable Internet.
  • Fiber-optic cable uses light to transmit data.
  • Wi-Fi uses wireless radio communication for network connectivity.
  • Bluetooth is mainly used for short-range device connections.
  • Different cable categories provide different capabilities.
