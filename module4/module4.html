MODULE 4

Home Networking and Wireless Configuration

Understanding home networks, network components, connection media, Internet connectivity, routers, wireless settings, and basic configuration.

Introduction

A home network allows computers, smartphones, printers, smart devices, and other equipment to communicate with each other and access the Internet. Understanding how these devices are connected helps us understand how everyday networks work.

In this module, we will explore the components used to build a home network, different types of network connections and cables, Internet connectivity, home and small-business routers, and wireless network configuration.

We will also put these concepts into practice by configuring a home network in Cisco Packet Tracer and observing how devices communicate across the network.

What We Will Learn

01

Home Network Basics

Learn what a home network is and identify the devices, components, standards, and basic security practices used to build one.

02

Network Media and Connections

Explore wired and wireless connections, UTP, coaxial cable, fiber-optic cable, Ethernet, Bluetooth, Cat5e, Cat6, and other standards.

03

Internet Connectivity

Understand ISPs, modems, DSL, cable Internet, coaxial connections, splitters, and how a home network connects to the Internet.

04

Home and Small-Business Routers

Learn what routers do and understand WAN, Internet, and LAN ports, DHCP, NAT, default gateways, and the role of a router in a home network.

05

Wireless Network Settings

Learn about IEEE 802.11, mixed mode, SSID, SSID broadcast, wireless channels, and the basic settings of a Wi-Fi network.

06

Wireless Router Configuration

Learn how to access a router's graphical interface using a computer, configure wireless settings, and connect wireless clients.

07

Complete Home Network Lab

Build and configure a complete home network in Cisco Packet Tracer, test connectivity, and use packet simulation to observe communication.

Putting It Together

A home network is made up of several components that work together. Devices need a way to connect, communicate, and access resources such as the Internet. The router, network media, wireless technologies, and configuration settings all play an important role.

By the end of this module, you should be able to identify common home networking components, explain different connection types, understand how a home connects to the Internet, identify the main parts of a wireless router, and configure a basic network in Packet Tracer.
