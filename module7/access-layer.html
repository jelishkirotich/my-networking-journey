MODULE 7

Access Layer

Understanding the role of the access layer and how it provides network connectivity for end devices.

1. What Is the Access Layer?

The access layer is the part of a network where end devices connect to the network. It is the point where computers, printers, IP phones, access points, and other devices gain access to network resources.

In a traditional hierarchical network design, the access layer is the layer closest to the users and their devices.

Think about a school computer laboratory. The computers need somewhere to connect their Ethernet cables. Those cables usually connect to an Ethernet switch. The switch provides the connection between the computers and the rest of the network.

Simple Access-Layer Example

PC      Laptop      Printer

↓          ↓          ↓

Access Switch

↓

Other Network Devices

The access switch is therefore an important part of the access layer. It provides physical and logical connectivity between the end devices and the rest of the network.

Simple definition:

The access layer is the part of the network that connects end devices to the network and provides access to network communication and resources.

2. Devices Connected at the Access Layer

Many different types of devices can connect to a network through the access layer.

Common End Devices

  • Desktop computers
  • Laptops
  • Smartphones
  • Network printers
  • IP phones
  • Servers
  • Security cameras
  • IoT devices

These devices are called end devices because they are usually the source or destination of network communication.

For example, when you send a file from your laptop to a network printer, your laptop is the source and the printer is the destination.

Remember:

End devices generate or receive network data. Network devices such as switches help that data reach its destination.

3. The Access Switch

An Ethernet switch is one of the most important devices found at the access layer.

A switch connects multiple devices within a local network and forwards Ethernet frames between them.

For example, imagine four computers connected to the same switch:

PC0          PC1
↓            ↓

Ethernet Switch

↑            ↑
PC2          PC3

The switch provides the local connection between these devices.

When one computer sends an Ethernet frame, the switch examines information in that frame and determines how it should be handled.

Later in this module, we will examine exactly how the switch makes these forwarding decisions using MAC addresses.

4. What Happens at the Access Layer?

The access layer is responsible for more than simply providing a place to plug in an Ethernet cable.

It is where devices gain access to the network and where local network communication begins.

Consider a laptop connected to a switch.

The laptop uses its network interface to transmit information. The physical medium carries the electrical signals, and the switch receives the Ethernet frame.

The switch then uses information from the frame to determine what should happen next.

This is where several concepts we will study in this module begin to connect:

5. Improving Communication at the Access Layer

A well-designed access layer should allow devices to communicate efficiently and reliably.

Several technologies and design choices help achieve this.

Using Switches Instead of Hubs

Older Ethernet networks often used devices called hubs. A hub does not make forwarding decisions based on MAC addresses. Instead, it repeats incoming signals to its other ports.

Modern Ethernet LANs use switches because switches can make forwarding decisions and provide more efficient communication.

Full-Duplex Communication

Modern switched Ethernet commonly operates using full-duplex communication.

Full-duplex means a device can transmit and receive simultaneously.

Half-Duplex Full-Duplex
Communication can occur in both directions, but not simultaneously. Communication can occur in both directions simultaneously.
Associated with shared-medium Ethernet and older technologies. Common with modern switched Ethernet.

Appropriate Network Speeds

Network interfaces and switches should support speeds appropriate for the requirements of the network.

Ethernet technologies have evolved from relatively slow connections to modern networks capable of very high data rates.

The actual speed available to a device depends on factors such as the network interface, switch port, cabling, and negotiated link speed.

Reducing Unnecessary Traffic

Network design can also reduce unnecessary traffic. For example, segmentation techniques such as VLANs can separate groups of devices into different logical broadcast domains.

VLANs are an important topic in switching, but we will only introduce the concept here. We will study them more deeply when we reach the appropriate networking topics.

6. Collision Domains

To understand why switches improved Ethernet networks, we need to understand the idea of a collision domain.

A collision occurs when two devices attempt to transmit on a shared communication medium at the same time.

Older shared Ethernet networks could experience collisions because multiple devices were sharing the same communication medium.

Hub-Based Network

PC0      PC1      PC2
\        |        /
Hub

Shared communication medium

Because devices connected through a traditional hub share the same collision domain, simultaneous transmissions could interfere with one another.

Switched Network

PC0      PC1      PC2
↓        ↓        ↓
Switch

In a modern switched Ethernet network operating in full duplex, each switch port provides a separate collision domain. Because the devices can transmit and receive simultaneously, traditional Ethernet collisions are not normally an issue on those links.

Important:

Do not confuse a collision domain with a broadcast domain. They describe different concepts.

A switch separates collision domains between its ports, while a normal Layer 2 switch does not automatically separate the entire network into different broadcast domains. VLANs are commonly used to create separate broadcast domains.

7. Broadcast Communication

Ethernet communication is not always one device sending data to one specific device.

Sometimes a device needs to send information to all devices within a particular local broadcast domain.

Ethernet uses the broadcast MAC address:

FF:FF:FF:FF:FF:FF

A Layer 2 broadcast frame is normally flooded by a switch within the relevant broadcast domain.

One example is ARP. When a device needs to discover the MAC address associated with an IPv4 address on its local network, it can send an ARP request as a broadcast.

We have already encountered ARP in earlier modules. Here, we're connecting it to the access layer and Ethernet switching.

9. Access Layer: Key Ideas

Concept Meaning
Access Layer The part of the network where end devices connect to the network.
Access Switch A switch that provides connectivity for end devices.
Ethernet A family of technologies and standards used for wired local-area networking.
NIC A network interface that allows a device to communicate over a network.
MAC Address A Layer 2 address used by Ethernet for local delivery.
Ethernet Frame The Layer 2 unit of data used for Ethernet communication.
Collision Domain A portion of a network where simultaneous transmissions could potentially collide in shared-medium Ethernet.
Broadcast Domain The group of devices that can receive a Layer 2 broadcast within the same broadcast domain.
