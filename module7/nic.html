Network Interface Card (NIC)

Learn what a Network Interface Card is, how it connects a device to a network, how it sends and receives Ethernet frames, and how it works together with MAC addresses and switches.

1. What Is a Network Interface Card?

A Network Interface Card (NIC) is the network interface that allows a device to communicate over a network.

A computer needs some way to connect its operating system and networking protocols to the actual network medium. The NIC provides that connection.

For a wired Ethernet connection, the NIC provides the interface through which Ethernet communication takes place over the network cable.

Simple definition

A NIC is the interface that allows a device to send and receive network data.

IEEE 802.3 defines Ethernet operation at the physical layer and the Data Link Layer's MAC sublayer, including operation over media such as twisted-pair copper and fiber.

2. Why Does a Computer Need a NIC?

A computer can perform calculations and run applications without being connected to a network.

However, if the computer needs to communicate with another device, it needs a network interface.

The NIC provides the connection between the computer's networking system and the network.

3. What Does a NIC Look Like?

A NIC does not always look like a separate expansion card.

On older desktop computers, a network interface could be installed as a separate card inside the computer.

Modern computers commonly have networking interfaces built directly into the motherboard or system.

A laptop may have:

  • A built-in wired Ethernet interface
  • A built-in Wi-Fi interface
  • Or both

External USB network adapters can also provide a network interface.

Important idea

"NIC" refers to the network interface, not necessarily a particular physical card that you can remove from the computer.

5. What Does a NIC Actually Do?

The NIC performs several important functions that allow a device to participate in network communication.

Function 1: Provides Network Connectivity

The NIC provides the interface between the device and the network.

For a wired Ethernet connection, this means providing the connection to the Ethernet physical medium.

Function 2: Sends Network Data

When a computer needs to transmit information, the networking system eventually provides information to the network interface for transmission.

The NIC participates in preparing the Ethernet transmission and sends the resulting signal through the physical interface.

Function 3: Receives Network Data

The NIC also works in the opposite direction.

It receives signals from the network, interprets them according to the relevant physical and data-link mechanisms, and passes received information to the computer's networking system.

Function 4: Works With MAC Addressing

An Ethernet interface has a MAC address used for Layer 2 communication.

Ethernet frames contain source and destination MAC addresses, which are used by network interfaces and switches during local network communication.

6. NIC and MAC Address

One of the most important things to understand is the relationship between a NIC and a MAC address.

Network Interface

↓

Has a MAC address used for Layer 2 communication

A traditional Ethernet MAC address is 48 bits long and is normally written as six groups of hexadecimal digits.

Example MAC address:

00:1A:2B:3C:4D:5E

The MAC address is associated with the network interface rather than simply with the entire computer.

Why does this matter?

A single computer can have multiple network interfaces.

For example, a laptop could have:

  • A wired Ethernet interface
  • A Wi-Fi interface
  • A virtual network interface

These interfaces can have different MAC addresses.

7. Is a MAC Address Permanently Burned Into the NIC?

You may sometimes hear that a MAC address is "burned into" a NIC.

This is a useful beginner description of traditionally manufacturer-assigned MAC addresses, but it is not the complete modern picture.

A network interface can have a factory-assigned address, while software or firmware can also use a locally administered address in appropriate situations.

IEEE's address format includes a bit that distinguishes universally administered addresses from locally administered addresses.

For your notes

A MAC address is a Layer 2 address associated with a network interface. Do not think of it as an unchangeable serial number permanently identifying the entire computer.

11. Do Not Confuse a NIC With a Switch

These two devices are both involved in Ethernet networking, but they have very different roles.

Simple way to remember

13. NIC Speed and Ethernet Standards

Ethernet interfaces can support different transmission speeds depending on the technology and hardware.

Ethernet has developed from early lower-speed technologies to modern high-speed Ethernet systems. IEEE 802.3 covers a broad range of Ethernet speeds and physical implementations.

Examples you may encounter include:

  • 10 Mbps Ethernet
  • 100 Mbps Fast Ethernet
  • 1 Gbps Gigabit Ethernet
  • 10 Gbps Ethernet
  • Higher-speed Ethernet technologies

The actual speed used depends on the capabilities of the NIC, switch port, cable or fiber, and the negotiated or configured Ethernet technology.

14. Complete Example: PC0 Communicating With PC1

Let's bring everything together.

Step 1: PC0 Creates Data

An application on PC0 creates information that needs to be sent across the network.

Step 2: Networking Protocols Prepare the Data

The data moves through the networking stack and receives the information required by the different protocols.

Step 3: Ethernet Creates a Frame

Ethernet prepares a frame containing information such as:

  • Destination MAC address
  • Source MAC address
  • Length/Type information
  • Payload
  • FCS

Step 4: PC0's NIC Transmits It

PC0's NIC sends the Ethernet transmission through the physical network connection.

Step 5: The Switch Receives It

The switch receives the frame on one of its ports.

Step 6: The Switch Learns PC0's MAC

The switch examines the source MAC address and associates it with the port where the frame arrived.

Step 7: The Switch Checks PC1's MAC

The switch examines the destination MAC address and checks its MAC address table.

Step 8: The Switch Forwards the Frame

If the destination MAC is known, the switch forwards the frame through the corresponding port.

Step 9: PC1's NIC Receives the Frame

PC1's NIC receives the Ethernet transmission and processes the frame.

Step 10: PC1 Processes the Data

The information continues through PC1's networking stack until it reaches the appropriate application.

15. NIC: Key Ideas to Remember

  • A NIC provides a device with a network interface.
  • A NIC can send and receive network traffic.
  • Ethernet NICs participate in Ethernet communication.
  • A network interface has a MAC address used for Layer 2 communication.
  • A computer can have multiple network interfaces.
  • The NIC and switch perform different jobs.
  • Ethernet involves both physical transmission and Data Link Layer MAC functions.
