MODULE 7

Access Layer and Ethernet

Understanding how devices communicate across Ethernet networks, how Ethernet frames are created and delivered, and how switches use MAC addresses to control communication within a local network.

Welcome to Module 7

In the previous modules, we introduced computer networks, network devices, network connections, wireless communication, and the physical media used to carry data.

In this module, we are going to move deeper into what happens when devices communicate inside a local Ethernet network. Instead of only looking at whether two devices can communicate, we will examine how that communication actually takes place.

We will focus particularly on the access layer, Ethernet, the Data Link Layer, network interface cards, MAC addresses, Ethernet frames, encapsulation, and Ethernet switches.

Why is this module important?

A computer connected to a network does not simply send data directly to another computer. Before information can travel across an Ethernet network, it must be prepared, addressed, formatted, transmitted, received, and processed.

Understanding these steps will make concepts such as MAC addresses, switching, ARP, packets, and frames much easier to understand.

The Big Picture

One of the best ways to understand this module is to imagine two computers communicating through an Ethernet switch.

PC1

PC0 does not simply place an application message onto the cable. The information is processed through the networking layers and eventually placed inside an Ethernet frame.

The frame contains important information such as the source MAC address and destination MAC address.

When the switch receives the frame, it examines the Ethernet information and uses its MAC address table to determine how the frame should be handled.

The destination computer's network interface then receives the frame and passes the appropriate information upward through the networking layers for processing.

Important Distinctions

As we move through this module, several networking terms may sound similar. It is important not to treat them as the same thing.

Concept What It Means
IP Address A logical address used at the Network Layer for communication between networks.
MAC Address A Layer 2 address used for Ethernet communication on a local network.
NIC A network interface that allows a device to connect to and communicate over a network.
Packet A unit of data associated with the Network Layer.
Frame A Layer 2 unit of data used for local network delivery.
Switch A network device that forwards Ethernet frames using information such as MAC addresses.

How We Will Study This Module

This module is designed to move from the simple idea of network communication into the details behind that communication.

We will first understand the concepts theoretically. Then we will connect them to what we can observe in Cisco Packet Tracer.

Our approach:

The goal is not simply to memorize the names of Ethernet frame fields or the steps a switch follows. The goal is to understand why each part exists and how the parts work together.
