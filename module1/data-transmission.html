1. Introduction to Data Transmission

Data transmission is the process of transferring data from one device or location to another through a communication medium.

In computer networks, information such as text, images, audio, video and files must be converted into signals that can travel through a physical or wireless medium.

Key idea: Data transmission describes how information moves from a sender to a receiver across a network.

→
Data

Receiver

For example, when a laptop sends a file to a server, the file is represented as digital data. The network interface converts the data into signals that can travel through Ethernet cable, fiber optic cable or a wireless connection.

2. Components of Data Transmission

A basic communication system contains several components that work together to move information from one point to another.

01

Sender

The sender is the device that generates and sends the data. Examples include computers, smartphones, servers and network devices.

02

Message

The message is the actual information being transmitted. It may be text, an image, audio, video or another type of data.

03

Transmission Medium

The medium provides the path through which the signal travels. It can be wired or wireless.

04

Receiver

The receiver is the device that receives the transmitted information.

05

Protocol

Protocols provide rules that devices use to communicate and interpret transmitted information.

06

Signal

A signal is the physical representation used to carry information through the transmission medium.

Remember: Data is the information being communicated. A signal is the physical form used to carry that information across a medium.

3. Data and Signals

Computers work with digital information represented as bits. A bit has one of two possible values: 0 or 1.

However, a bit cannot simply travel through a cable or through the air by itself. The information must be represented by a signal.

Depending on the transmission technology, signals can be represented using electrical changes, light pulses or electromagnetic waves.

Example: Ethernet

When a computer sends data through an Ethernet cable, the network interface converts the digital information into electrical signals that travel through the cable.

Example: Fiber Optic

Fiber optic communication uses pulses of light to carry information through optical fiber.

Example: Wi-Fi

Wi-Fi uses radio waves to transmit information between wireless devices and access points.

4. Analog and Digital Signals

Signals can generally be described as analog or digital.

Analog Signal

An analog signal changes continuously over time.

Digital Signal

A digital signal uses discrete levels to represent information.

Feature Analog Digital
Nature Continuous Discrete levels
Representation Continuously varying signal Discrete values representing data
Typical networking context Used in some communication systems Dominant in modern computer networking
Example Traditional voice signal Computer data
Important distinction: Digital data and digital signals are related but are not exactly the same thing. Digital data is information represented using values such as 0 and 1. A digital signal is a physical signal used to represent that information during transmission.

5. Serial and Parallel Transmission

Data can be transmitted serially or in parallel depending on how the bits are sent across the communication path.

Serial Transmission

In serial transmission, bits are sent one after another over a communication channel.

Serial Transmission
1 → 0 → 1 → 1 → 0 → 0 → 1 → 0

The bits travel sequentially.

Parallel Transmission

In parallel transmission, multiple bits are transmitted at the same time using multiple communication paths.

Parallel Transmission
Bit 1: 1
Bit 2: 0
Bit 3: 1
Bit 4: 1

Multiple bits can travel simultaneously using separate paths.

Feature Serial Parallel
Bit transmission One after another Multiple bits at the same time
Number of paths Usually fewer communication paths Multiple paths
Distance Well suited to many modern communication links Often more suitable for shorter connections
Modern networking Widely used Less common for long-distance network communication
Key point: Modern high-speed networking commonly uses serial communication because it can provide high data rates while avoiding some timing and synchronization problems associated with sending many bits simultaneously.

6. Synchronous and Asynchronous Transmission

Synchronous Transmission

Synchronous transmission sends data using coordinated timing between the communicating systems. Data is commonly organized into larger blocks or frames.

Asynchronous Transmission

Asynchronous transmission does not require a shared clock signal between the sender and receiver. Instead, the communication system can use mechanisms such as start and stop bits to identify individual characters or bytes.

7. Transmission Modes

Transmission modes describe the direction in which data can flow between communicating devices.

Simplex

One-Way Communication

Data travels in only one direction.

Sender → Receiver

Example: a traditional broadcast system.

Half-Duplex

Two-Way, One Direction at a Time

Both devices can transmit, but not at the same time.

A → B
B → A

Example: traditional walkie-talkie communication.

Full-Duplex

Two-Way Simultaneous

Both devices can send and receive data at the same time.

A ↔ B

Example: a telephone conversation.

Networking example: Modern switched Ethernet links commonly operate in full-duplex mode, allowing devices to transmit and receive simultaneously.

8. Wired Transmission Media

Wired transmission uses a physical cable or conductor to carry signals between devices.

Twisted-Pair Cable

Twisted-pair cables contain pairs of copper wires twisted together to reduce interference.

Ethernet networks commonly use twisted-pair cables such as Cat5e, Cat6 and Cat6a.

Coaxial Cable

Coaxial cable contains a central conductor surrounded by insulation and shielding.

It is used in applications such as cable television and some broadband communication systems.

Fiber Optic Cable

Fiber optic cable transmits information using light through optical fiber.

Fiber supports high bandwidth and long-distance communication with low signal loss compared with many copper links.

Medium Main Signal Common Uses

9. Wireless Transmission Media

Wireless transmission allows devices to communicate without a physical cable between the communicating endpoints.

Radio Waves

Radio waves are widely used for wireless communication. Wi-Fi and Bluetooth are common examples.

Microwave

Microwave communication can be used for point-to-point links and other telecommunications systems.

Infrared

Infrared uses electromagnetic radiation at wavelengths longer than visible light. It can be used for short-range communication.

Wireless does not mean signal-free. Wireless networks still use physical electromagnetic signals. The difference is that the communication path does not require a physical cable connecting the devices.

10. Factors Affecting Data Transmission

The quality and performance of data transmission can be affected by several factors.

Distance

Longer distances can cause signal attenuation and may require additional network equipment or suitable transmission technology.

Interference

Electrical or electromagnetic interference can affect signal quality, especially on some copper and wireless links.

Noise

Unwanted signals can interfere with the intended communication and cause transmission errors.

Bandwidth

The capacity of a communication link influences how much data can potentially be transmitted within a given period.

Medium Quality

The quality and characteristics of cables, connectors and wireless environments affect communication performance.

Network Congestion

Heavy traffic can reduce the effective rate at which data is successfully delivered.

Important: A network link may have a high theoretical capacity but still deliver less data in practice because of interference, congestion, protocol overhead, equipment limitations and other conditions.

11. Data Transmission in the Real World

Data transmission happens continuously in everyday network activities. The following examples show how the concepts connect together.

Example 1: Sending a WhatsApp Message

A smartphone creates digital data when a message is typed. The device processes the data and sends it through a wireless connection. The wireless signal reaches an access point or mobile network infrastructure, after which the data can travel through wired and wireless networks until it reaches the destination.

Example 2: Watching a Video

When streaming a video, data is transmitted from a remote server toward the user's device. The data may travel through fiber optic links, routers, switches, wireless access points and other network infrastructure before reaching the screen.

Example 3: Accessing a Website

When a user enters a website address, the computer sends requests across the network. Servers process the requests and send data back to the user's device. The returned information is then interpreted by the browser.

Think about it: The path between two devices does not necessarily use only one transmission medium. A single communication session can involve Wi-Fi, copper Ethernet, fiber optic links and wireless telecommunications at different points.

13. Module Summary

Data transmission is the process of moving information from a sender to a receiver through a communication medium.

Key points to remember:
  • Data transmission moves information between devices.
  • Data is represented by signals when it travels through a network.
  • Signals can be analog or digital.
  • Serial transmission sends bits sequentially.
  • Parallel transmission sends multiple bits simultaneously using multiple paths.
  • Synchronous transmission uses coordinated timing.
  • Asynchronous transmission uses framing mechanisms such as start and stop bits.
  • Simplex allows one-way communication.
  • Half-duplex allows communication in both directions, but not simultaneously.
  • Full-duplex allows communication in both directions simultaneously.
  • Wired media include twisted pair, coaxial and fiber optic cable.
  • Wireless communication can use radio waves, microwaves and infrared.
  • Distance, interference, noise, bandwidth, medium quality and congestion can affect transmission.
