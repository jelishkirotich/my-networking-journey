Module 1 Glossary

Short definitions for the terms used in this module. Type to filter.

Address Resolution Protocol (ARP)
Protocol
Lets an IPv4 device find the MAC address that belongs to an IP address on the local network.
Bandwidth
Performance
The capacity of a connection, or the most data it can carry per second. Measured in bits per second.
Bit and byte
Units
A bit is a 0 or a 1. A byte is 8 bits. Mbps means megabits per second, MB/s means megabytes per second.
Frame
Data
The unit of data at the data link layer. An Ethernet frame carries source and destination MAC addresses.
Full duplex
Transmission
Both devices send and receive at the same time. Modern switched Ethernet links work this way.
Half duplex
Transmission
Both devices can send, but only one at a time, like a walkie talkie.
ICMP
Protocol
Internet Control Message Protocol. Carries control and error messages, and powers ping.
IP address
Addressing
A logical address given to a network interface so devices can find each other across networks.
LAN
Network type
Local Area Network. Connects devices in a home, office or building.
MAC address
Addressing
A 48 bit hardware address on a network interface, used for delivery inside a local network.
MAC address table
Switching
The list a switch builds of MAC addresses and the port each one was learned on.
MAN
Network type
Metropolitan Area Network. Connects sites across a city.
Packet
Data
The unit of data at the network layer. An IPv4 packet carries source and destination IP addresses.
PAN
Network type
Personal Area Network. A phone connected to earbuds or a watch is an example.
Ping
Tool
A command that sends an ICMP echo request and waits for an echo reply to test reachability.
Protocol
Concept
A set of rules that devices follow to communicate.
Router
Device
Connects different networks and forwards packets using IP addresses.
Serial transmission
Transmission
Bits are sent one after another over a single path.
Switch
Device
Connects devices inside a local network and forwards frames using MAC addresses.
Throughput
Performance
The data rate actually achieved. It is usually lower than bandwidth.
VPN
Network type
Virtual Private Network. A protected logical connection across another network such as the Internet.
WAN
Network type
Wide Area Network. Connects networks across regions, countries or continents.
