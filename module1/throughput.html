1. Introduction to Throughput

Throughput is the actual amount of data that is successfully transferred from one point to another over a network during a given period of time.

In simple terms, throughput tells us how much data a network is actually delivering. It is therefore an important way of understanding the real performance of a network connection.

For example, an Internet connection may be advertised as capable of 100 Mbps, but a device may actually receive data at only 75 Mbps during a particular download. The 75 Mbps is an example of the connection's actual throughput at that moment.

Simple definition:

Throughput is the actual rate at which data is successfully transferred across a network.

Why is Throughput Important?

Throughput helps us understand how a network performs under real operating conditions.

Two networks may have the same advertised connection speed but provide different actual performance because of congestion, interference, hardware limitations, or other network conditions.

Measuring throughput therefore gives us a better picture of what users are actually experiencing.

A Simple Example

Network Connection
100 Mbps maximum capacity

↓

Actual data transfer
72 Mbps

↓

Throughput = 72 Mbps

2. Measuring Throughput

Throughput is normally measured in bits per second (bps). Larger networks and modern Internet connections commonly use larger units such as Kbps, Mbps, and Gbps.

Common Units

Unit Meaning Approximate Value
bps bits per second 1 bit/s
Kbps kilobits per second 1,000 bits/s
Mbps megabits per second 1,000,000 bits/s
Gbps gigabits per second 1,000,000,000 bits/s

Bits vs Bytes

Networking speeds are normally expressed in bits per second, while file sizes are commonly displayed in bytes.

A byte contains 8 bits.

1 Byte = 8 bits

100 Mbps ÷ 8 ≈ 12.5 MB/s

Therefore, a theoretical 100 Mbps connection corresponds to approximately 12.5 megabytes per second (MB/s) before accounting for protocol overhead and other real-world limitations.

Important:

Do not confuse Mbps with MB/s. The capital "B" represents bytes, while the lowercase "b" represents bits.

3. Throughput and Data Rate

Throughput and data rate are closely related terms, but they should not always be treated as exactly the same thing.

Data Rate

Data rate generally describes the rate at which bits are transmitted or the rate a connection is designed to support. For example, an Ethernet link may have a data rate of 1 Gbps.

Throughput

Throughput describes the amount of data that is successfully transferred during actual communication.

A link may have a data rate of 1 Gbps while the actual application throughput is lower because of network conditions and protocol overhead.

Link Data Rate
1 Gbps

↓

Network conditions + Protocol overhead

↓

Actual Throughput
850 Mbps
Remember:

The available or configured data rate describes what a connection can support, while throughput describes what is actually being successfully delivered.

4. Factors Affecting Throughput

Throughput can change depending on the condition of the network and the equipment being used.

1. Network Congestion

Congestion occurs when many devices attempt to send large amounts of data through the network at the same time.

When network resources become heavily used, the amount of data that can be successfully delivered to an individual device may decrease.

2. Network Hardware

Network interfaces, switches, routers, wireless access points, and other equipment can affect the maximum performance of a connection.

If one device or link is slower than the others, it can become a bottleneck.

3. Wireless Interference

Wireless networks can experience interference from other wireless devices, physical obstacles, distance, and competing networks.

These conditions can reduce the amount of data that can be successfully transferred.

4. Distance

The distance between communicating devices can affect network performance, particularly in wireless networks and certain physical transmission media.

5. Protocol Overhead

Network communication requires headers, control information, acknowledgements, and other protocol mechanisms.

This information is necessary for communication, but it means that not every transmitted bit represents application data.

6. Network Errors and Retransmissions

If data is lost or corrupted, some protocols may require data to be transmitted again.

Retransmissions consume network capacity and can reduce effective throughput.

Main idea:

Throughput is affected by everything that influences how efficiently data can travel through the network.

5. Real-World Throughput Example

Consider a student using a 100 Mbps Internet connection to download a large file.

The connection has a maximum advertised rate of 100 Mbps, but the actual download may not reach exactly 100 Mbps.

Possible Situation

Advertised connection: 100 Mbps

Network congestion: Moderate

Wireless interference: Present

Actual download throughput: 68 Mbps

In this situation, the connection has a 100 Mbps advertised rate, but the actual throughput is 68 Mbps.

This does not necessarily mean that the Internet Service Provider is failing to provide the advertised connection. Actual performance can depend on many factors between the user's device and the destination server.

Download Example

Suppose a file is 800 megabytes (MB) and the actual throughput is 80 Mbps.

Because throughput is measured in bits while the file size is measured in bytes, we first convert the file size into bits.

800 MB × 8
= 6,400 megabits

Transfer time
= 6,400 Mb ÷ 80 Mbps
= 80 seconds

Under these simplified conditions, the transfer would take approximately 80 seconds. Real downloads can take longer or vary because throughput can change during the transfer.

6. Throughput and Network Performance

Throughput is one of several measurements that can be used to understand network performance.

A network with higher throughput can generally transfer more data in the same amount of time, assuming other conditions remain comparable.

Throughput in Different Activities

Activity Why Throughput Matters
Downloading files Higher throughput can reduce download time.
Streaming video Sufficient throughput helps maintain the required video quality.
Cloud applications Higher throughput can improve the transfer of data between the user and cloud services.
Large file backups Higher throughput can reduce the time required to transfer large amounts of data.

Throughput Is Not the Only Measurement

A network can have high throughput while still having other performance problems.

For example, latency measures the time it takes for data to travel between endpoints, while packet loss describes data packets that fail to reach their destination.

Therefore, network performance should be evaluated using multiple factors rather than throughput alone.

7. Throughput vs Bandwidth

Bandwidth and throughput are closely related, but they describe different things.

Bandwidth Throughput
Describes the maximum capacity or available data rate of a connection. Describes the actual amount of data successfully transferred.
Often expressed in Mbps or Gbps. Also commonly expressed in Mbps or Gbps.
Represents what the connection can potentially carry. Represents what is actually achieved.
Can be thought of as network capacity. Can be thought of as actual network performance.

A Simple Analogy

Imagine a highway with several lanes.

Highway Capacity
= Bandwidth

↓

Actual Vehicles Moving
= Throughput

A highway may have enough lanes to carry many vehicles, but traffic congestion, accidents, or other problems may prevent vehicles from moving at the maximum possible rate.

Similarly, a network may have high bandwidth while actual throughput is lower.

The key distinction:

Bandwidth is capacity.
Throughput is actual successful delivery.

8. Improving Throughput

If a network is experiencing low throughput, network administrators can investigate the cause and improve the network where possible.

Possible Improvements

  • Upgrade slow network hardware.
  • Increase the capacity of important network links.
  • Reduce unnecessary network traffic.
  • Improve wireless coverage and reduce interference.
  • Replace damaged or unsuitable cables.
  • Identify and remove network bottlenecks.
  • Configure the network appropriately for the expected workload.

Finding a Bottleneck

A bottleneck is a part of a network that limits the performance of the entire communication path.

Remember:

Improving throughput often requires identifying the part of the network that is limiting actual data transfer.

10. Throughput Summary

Throughput is the actual rate at which data is successfully transferred across a network.

It is normally measured in bits per second, with common units including Kbps, Mbps, and Gbps.

Throughput can be lower than the maximum capacity or data rate of a connection because of congestion, hardware limitations, wireless interference, distance, protocol overhead, packet loss, and other network conditions.

Throughput is important because it helps us understand the actual performance experienced when transferring data across a network.

What you should remember:
  • Throughput is the actual successful data transfer rate.
  • Throughput is commonly measured in Mbps or Gbps.
  • Throughput can change depending on network conditions.
  • Network congestion can reduce throughput.
  • Protocol overhead means not every transmitted bit is application data.
  • A bottleneck can limit throughput.
  • Bandwidth represents capacity, while throughput represents actual successful transfer.

The Big Picture

When studying computer networks, it is important to distinguish between what a network is capable of carrying and what it actually carries.

A connection may have high bandwidth, but real-world throughput can be lower. Understanding this difference helps network administrators identify performance problems and design networks that can handle the required amount of traffic.
