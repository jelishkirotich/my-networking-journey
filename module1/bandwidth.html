1. Introduction to Bandwidth

Bandwidth is the amount of data that a network connection can potentially carry over a given period of time.

In computer networking, bandwidth is commonly expressed as a number of bits per second. For example, a network connection may have a bandwidth of 100 Mbps or 1 Gbps.

Bandwidth is an important concept because it helps describe the capacity of a network connection.

Simple definition:

Bandwidth is the capacity of a network connection to carry data over time.

A Simple Analogy

Imagine a road connecting two towns.

A narrow road can carry fewer vehicles at the same time, while a wider road with more lanes can carry more vehicles.

In this analogy, the number of lanes represents bandwidth. More lanes provide greater capacity for vehicles.

Similarly, greater network bandwidth provides a connection with greater capacity to carry data.

2. What Bandwidth Means

When a network connection is described as having a particular bandwidth, the value indicates the amount of data the link is designed or rated to carry per second under the relevant conditions.

For example, if an Ethernet connection is rated at 1 Gbps, the link has a nominal capacity of 1 gigabit per second.

Example

Network Link: 1 Gbps

Meaning: The link has a nominal capacity of 1,000,000,000 bits per second.

This does not mean that an application will always receive exactly 1 Gbps of useful data. Real network performance can be affected by many factors.

Important:

Bandwidth describes capacity. It should not automatically be interpreted as the amount of application data that is actually being delivered.

Bandwidth and Network Capacity

A connection with greater bandwidth can potentially carry more data during the same period of time than a connection with lower bandwidth, assuming comparable conditions.

3. Measuring Bandwidth

Bandwidth is commonly measured in bits per second (bps). Because modern networks can carry very large amounts of data, larger units are normally used.

Unit Full Name Value
bps bits per second 1 bit/s
Kbps kilobits per second 1,000 bits/s
Mbps megabits per second 1,000,000 bits/s
Gbps gigabits per second 1,000,000,000 bits/s

Bits and Bytes

Networking bandwidth is normally expressed in bits per second, while file sizes are commonly expressed in bytes.

1 Byte = 8 bits

100 Mbps ÷ 8
≈ 12.5 MB/s

Therefore, a 100 Mbps connection has a theoretical bit rate equivalent to approximately 12.5 megabytes per second before accounting for protocol overhead and other factors.

Watch the capital letters:

Mbps = megabits per second
MB/s = megabytes per second

A lowercase b means bits, while an uppercase B means bytes.

4. Types of Network Bandwidth

Bandwidth can be discussed in different networking contexts. The type of connection and communication technology can influence the bandwidth available to devices.

Wired Bandwidth

Wired networks use physical transmission media such as Ethernet cables and fiber-optic cables.

Different cable types and network technologies support different data rates.

Wireless Bandwidth

Wireless networks use radio signals to transmit data. Wireless technologies can provide high data rates, but actual performance can vary depending on signal conditions, interference, distance, and other factors.

Internet Connection Bandwidth

Internet Service Providers commonly advertise Internet connections using bandwidth values such as 20 Mbps, 50 Mbps, 100 Mbps, 500 Mbps, or 1 Gbps.

These values describe the service's advertised or provisioned connection rate, while actual throughput can vary.

Connection Example Bandwidth Typical Use

Gigabit Ethernet 1 Gbps High-speed local networks
Wi-Fi Varies by standard and conditions Wireless device connectivity

5. Real-World Bandwidth Examples

Bandwidth can be easier to understand when we connect the concept to situations we encounter every day.

Example 1: Home Internet

Imagine a home has an Internet connection with an advertised bandwidth of 100 Mbps.

The connection has the capacity to support data transfer at a nominal rate of up to 100 megabits per second, subject to the conditions and limitations of the service and network.

Example 2: University Network

A university may have a high-capacity Internet connection that serves hundreds or thousands of students and staff.

A larger amount of bandwidth allows the network to support many simultaneous users and applications, although how that capacity is shared and managed is also important.

Example 3: Data Center

Data centers can use high-speed network connections to allow servers to exchange very large amounts of data.

High bandwidth is particularly useful when large files, databases, backups, or application traffic need to be moved between systems.

6. Bandwidth as Network Capacity

One of the best ways to understand bandwidth is to think of it as the capacity available on a communication path.

If a connection has greater bandwidth, it can potentially carry more bits per second than a connection with lower bandwidth.

Comparing Two Links

Link A
100 Mbps

Link B
1 Gbps

1 Gbps = 1,000 Mbps

A 1 Gbps link has a nominal capacity ten times greater than a 100 Mbps link.

This means the 1 Gbps link can potentially carry ten times as many bits per second, assuming the links are being compared under appropriate and equivalent conditions.

Think of bandwidth as capacity:

A larger pipe can carry more water at once. Similarly, a higher-bandwidth network connection can carry more bits per second.

7. Shared Bandwidth

In many networks, available bandwidth is shared among multiple users or devices.

For example, several devices in a home may use the same Internet connection at the same time.

If several devices are actively transferring large amounts of data, they are competing for the available network capacity.

The exact amount available to each device depends on network configuration, traffic patterns, protocols, and traffic management.

Why This Matters

A 100 Mbps connection serving one active device is different from the same connection being heavily used by many devices simultaneously.

This is one reason why a user may experience different performance at different times of the day.

Important:

Total network bandwidth is not automatically the same as the amount of bandwidth available to every individual device at every moment.

8. Bandwidth vs Throughput

Bandwidth and throughput are two related networking concepts that are often confused.

A highway can have many lanes but still experience traffic congestion. Similarly, a network can have high bandwidth while actual throughput is lower.

The easiest way to remember:

9. Why Bandwidth Matters

Network bandwidth is important because applications and users require different amounts of network capacity.

Video Streaming

Video streaming requires a continuous flow of data. Higher bandwidth can allow a network to support higher-quality video and more simultaneous streams, provided other requirements are also satisfied.

Large File Transfers

High-bandwidth connections are useful when transferring large files, software packages, backups, and other large datasets.

Many Users

Networks serving many users generally require more total capacity than networks serving only a small number of users.

Cloud Services

Organizations increasingly depend on cloud applications and online storage. Adequate network capacity helps support the exchange of information between users and cloud services.

Network planning:

Network administrators consider expected users, devices, applications, traffic patterns, and future growth when determining how much bandwidth a network needs.

10. Bandwidth Summary & Quick Check

Summary

Bandwidth describes the capacity or nominal data rate of a network connection.

It is normally measured in bits per second, with common units including Kbps, Mbps, and Gbps.

Different network technologies and physical media can support different bandwidths.

Bandwidth may be shared among multiple users and devices, so the total capacity of a network is not automatically available to every device at the same time.

Most importantly, bandwidth should not be confused with throughput. Bandwidth represents capacity, while throughput represents actual successful data transfer.

What you should remember:
  • Bandwidth represents network capacity.
  • Bandwidth is commonly measured in bps, Kbps, Mbps, and Gbps.
  • A higher bandwidth connection can potentially carry more data per second.
  • Bandwidth can be shared among multiple devices.
  • Mbps and MB/s are different units.
  • Bandwidth does not guarantee a specific actual throughput.
