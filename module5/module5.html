MODULE 5

Communication Protocols and Models

Understanding how devices communicate, the protocols that control network communication, the TCP/IP and OSI models, and the standards that allow different devices and networks to communicate successfully.

Introduction

Network communication requires more than simply connecting two devices. Devices need agreed rules that determine how messages are created, transmitted, received, and understood. These rules are called communication protocols.

When a device sends information across a network, several protocols may work together. For example, a web request can involve HTTP at the application level, TCP at the transport level, IP at the Internet level, and Ethernet or Wi-Fi for communication across the local network.

In this module, we will explore how these protocols work together and study two important models used to understand network communication: the TCP/IP model and the OSI reference model.

We will also examine communication standards, protocol functions, encapsulation, decapsulation, and the journey of a message from a sender to a receiver.

Putting It Together

Network communication is a process involving many different protocols and technologies. A single message may pass through several layers, with each layer performing a specific function before the information is passed to the next layer.

The TCP/IP model helps us understand the protocols used in real-world Internet communication, while the OSI reference model provides a detailed framework for understanding the different functions involved in networking.

By the end of this module, you should be able to explain why protocols are necessary, describe how TCP/IP and OSI organize network functions, identify the role of important protocols, explain communication standards, and describe how data is encapsulated and decapsulated as it travels through a network.
