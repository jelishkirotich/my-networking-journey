Internet Connectivity

In the previous topics, we looked at network components, connections, devices, clients and servers. Now we can look at how a local network connects to the Internet.

When I open a website on my laptop, my laptop does not connect directly to the web server. The request passes through several devices and networks before reaching its destination.

What Is the Internet?

The Internet is a global network made up of many interconnected networks. These networks belong to homes, schools, businesses, organizations, Internet Service Providers and other networks around the world.

My local network is only one small network. To communicate with devices outside that network, it needs a connection to another network and eventually to the wider Internet.

Simple idea: The Internet is a network of networks that allows devices and networks around the world to communicate.

Local Network vs Internet

A local network, or LAN, connects devices within a limited location such as a home, school, office or laboratory.

The Internet connects many different networks together.

Local Network Internet
Usually covers a limited area Connects networks across the world
Devices may connect through a switch or Wi-Fi Many networks and routers are involved
Usually controlled by one organization or person Made up of many independently operated networks

How Does My Network Reach the Internet?

A typical connection can look like this:

Laptop → Wi-Fi → Access Point → Switch → Router → ISP → Internet → Web Server

Not every network will have exactly these devices. For example, a home network may combine several functions into one device. However, the basic idea remains the same: the local network needs a device that can forward traffic toward other networks.

The Router's Role

The router connects different networks and decides where network traffic should be forwarded.

In a home or school network, the router is commonly the device that connects the local network to the Internet through an ISP.

For example, when my laptop wants to communicate with a server on another network, it sends the traffic toward its router. The router then forwards the traffic toward the destination.

Remember: A switch mainly connects devices within a network, while a router connects different networks.

What Is an ISP?

ISP stands for Internet Service Provider.

An ISP provides the connection that allows a home, school, business or other organization to access the Internet.

Examples of ISPs in Kenya include companies such as Safaricom, Airtel and various fiber Internet providers.

The connection between the customer's network and the ISP can use different technologies, including fiber, mobile networks, cable or other broadband technologies.

Modem and ONT

Depending on the type of Internet connection, additional equipment may be used between the customer's network and the ISP.

Modem

A modem is a device used with certain types of Internet connections to communicate with the ISP's network over the provider's transmission medium.

ONT

ONT stands for Optical Network Terminal. It is commonly used with fiber Internet connections and provides the connection between the fiber network and the customer's Ethernet network.

Modern Internet equipment can combine several functions into one device. A single home gateway may contain routing, switching, Wi-Fi, firewall and DHCP functions, and depending on the connection, modem or other access equipment may also be integrated.

What Is a Default Gateway?

A default gateway is the device that a host uses when it needs to communicate with a destination outside its local network.

In many home and school networks, the default gateway is the local router.

For example, suppose my laptop has an IP address of 192.168.1.10 and the router has an address of 192.168.1.1.

If the laptop needs to communicate with another device on its local network, it may communicate directly with that device. If the destination is outside the local network, the laptop sends the traffic to its default gateway.

Simple way to remember: The default gateway is the way out of my local network.

Private and Public IP Addresses

Devices on a local network commonly use private IP addresses. These addresses are used inside local networks and are not directly routable across the public Internet.

Some commonly used private IPv4 ranges are:

  • 10.0.0.0 to 10.255.255.255
  • 172.16.0.0 to 172.31.255.255
  • 192.168.0.0 to 192.168.255.255

A public IP address is used for communication across the Internet. Your ISP or another network provider may assign a public address to the connection.

This is one reason the IP address shown on your laptop may be different from the public IP address associated with your Internet connection.

What Is NAT?

NAT stands for Network Address Translation.

NAT allows private IP addresses used inside a local network to communicate with destinations on the Internet by translating network addresses at the boundary of the local network.

This means that many devices inside a home or school network can share a public Internet connection.

Example: Several devices may have private addresses such as 192.168.1.10, 192.168.1.11 and 192.168.1.12, while they share one public Internet connection through the router.

DNS and Internet Connectivity

We previously learned that DNS translates domain names into IP addresses.

When I type: 

www.example.com

my device needs to find the IP address associated with that domain before it can communicate with the server.

This means DNS is an important part of accessing websites, but DNS is not the same thing as the Internet connection itself.

Important: A device can be connected to Wi-Fi but still be unable to access websites if there is a problem with the router, ISP, DNS or another part of the connection.

What Happens When I Open a Website?

Let's follow a simple example. I open my laptop and type a website address into my browser.

  1. My laptop connects to the local network using Wi-Fi or Ethernet.
  2. If I use Wi-Fi, the wireless traffic reaches the access point.
  3. The access point forwards the traffic into the wired network.
  4. The switch forwards the traffic toward the router.
  5. The router acts as the gateway to networks outside the local network.
  6. The router forwards the traffic toward the ISP.
  7. The ISP provides access to the wider Internet.
  8. The traffic eventually reaches the network containing the destination server.
  9. The server sends a response back through the network.
Laptop → Access Point → Switch → Router → ISP → Internet → Server → Response back to Laptop

Why Can Wi-Fi Work but the Internet Not Work?

Wi-Fi and Internet access are related, but they are not the same thing.

Your laptop can successfully connect to a wireless access point while the network still has no working Internet connection.

For example, the problem could be:

  • The router is not connected to the ISP.
  • The ISP connection is down.
  • The device has incorrect IP configuration.
  • The default gateway is unreachable.
  • DNS is not working.
  • A network device has failed.

Basic Internet Connectivity Troubleshooting

When a device cannot access the Internet, I can check the connection step by step instead of immediately assuming that the Internet itself is down.

  1. Check whether the device is connected to Wi-Fi or Ethernet.
  2. Check whether the device has an IP address.
  3. Check the default gateway.
  4. Test communication with the gateway.
  5. Test communication with an Internet IP address.
  6. Check whether DNS is working.

These checks help narrow down where the problem is occurring.

Following the Complete Connection

At this point, I can connect the ideas from the previous topics.

Laptop → Wi-Fi → Access Point → Switch → Router → ISP → Internet → Web Server

Each part has a different role. The laptop is an end device, the access point provides wireless connectivity, the switch connects devices on the local network, the router connects networks, the ISP provides Internet access, and the web server provides the requested service.

Understanding this path makes it easier to understand what happens when a network works and what might be wrong when it does not.

What to Remember

  • The Internet is a network of interconnected networks.
  • A LAN is a local network.
  • A router connects different networks.
  • An ISP provides Internet access.
  • The default gateway provides a path out of the local network.
  • Private IP addresses are commonly used inside local networks.
  • NAT allows private addresses to communicate through a shared public connection.
  • DNS helps translate domain names into IP addresses.
  • Being connected to Wi-Fi does not automatically mean the Internet is working.
