Device Connections

In the previous topic, I learned how network components can connect to form a network. Now I want to look more closely at the actual connections between individual devices.

This includes network ports, Ethernet cables, RJ-45 connectors, copper and fiber connections, Wi-Fi, and how different devices physically or wirelessly connect to each other.

1. How Does a Device Connect to a Network?

For a device to communicate on a wired network, it needs a network interface and a physical connection to another network device.

A typical wired connection looks like this:

Computer NIC → Ethernet Cable → Switch Port

The NIC provides the network interface on the computer. The Ethernet cable carries the signals, and the switch port provides the connection on the switch.

This is one of the basic physical connections I will later recreate in Cisco Packet Tracer.

2. Network Ports

A physical network port is the socket on a device where a network cable can be connected.

For example, a desktop computer may have an Ethernet port on its network interface, while a switch may have many Ethernet ports.

Switches commonly have multiple ports because they are designed to connect many devices at the same time.

Important:

A physical network port is not the same thing as a logical port such as TCP port 80 or TCP port 443. Physical ports are where cables connect. Logical ports are used by network services and applications.

3. Ethernet

Ethernet is one of the main technologies used for wired local area networks.

Ethernet allows devices to exchange data over a physical network connection.

A common Ethernet connection is:

Computer → Ethernet Cable → Switch

Ethernet can use different physical media, including copper twisted-pair cables and fiber-optic cables.

4. RJ-45 and Ethernet Connectors

The connector commonly seen on Ethernet cables using twisted-pair copper is often called an RJ-45 connector.

It is the small plastic connector that clicks into an Ethernet port.

Think of it like this:

The Ethernet port is the socket. The RJ-45 connector is the plug.

When the connector is inserted correctly, a small locking tab helps keep the cable securely in the port.

You will encounter these connectors frequently when working with physical Ethernet networks.

5. Twisted-Pair Ethernet Cable

Twisted-pair Ethernet cable contains pairs of copper wires twisted together.

The twisting helps reduce interference between the wires and allows the cable to carry network signals effectively.

Common categories include:

  • Cat5e
  • Cat6
  • Cat6a

Different cable categories support different performance characteristics and maximum distances depending on the Ethernet standard being used.

For now:

The most important thing to remember is that twisted-pair Ethernet is one of the most common physical media used to connect devices to switches and other network equipment.

6. Straight-Through Ethernet Cable

Traditionally, Ethernet cable types were often discussed as straight-through and crossover cables.

A straight-through cable has the same wiring standard on both ends.

Example:

T568A → T568A

or

T568B → T568B

Straight-through cables were traditionally used for connecting different types of devices, such as:

  • Computer → Switch
  • Computer → Hub
  • Router → Switch

Modern Ethernet equipment often supports auto-MDI/MDIX, which can automatically detect and adjust for different cable wiring. Because of this, the old rule of always needing a particular cable type is less important with modern equipment.

7. Crossover Ethernet Cable

A crossover cable has different wiring arrangements at its two ends.

Traditionally, crossover cables were used when connecting similar types of devices, such as:

  • Computer → Computer
  • Switch → Switch
  • Router → Router

The purpose was to cross the transmit and receive pairs so that the two devices could communicate correctly.

Modern equipment:

Many modern Ethernet interfaces support auto-MDI/MDIX, meaning they can automatically detect the required transmit and receive arrangement.

Even though the distinction is less important in modern physical networks, understanding crossover cables is useful when learning networking fundamentals and working with Packet Tracer.

8. T568A and T568B

T568A and T568B are two wiring standards that define the order of the individual wires inside an Ethernet connector.

The eight wires are arranged into four twisted pairs.

Important idea:

T568A and T568B do not describe different types of Ethernet technology. They describe different wire arrangements used when terminating twisted-pair cable.

If the same standard is used on both ends, the cable is straight-through.

If one end uses T568A and the other uses T568B, the cable is a crossover cable.

9. Copper vs Fiber

Not every wired network connection uses copper Ethernet cable. Fiber-optic cable is another important networking medium.

Feature Copper Fiber
Signal Electrical Light
Common use Local device connections High-speed and longer-distance connections
Resistance to electromagnetic interference More susceptible Highly resistant
Physical medium Copper wires Optical fiber

Both technologies can be used to create high-speed network connections. The appropriate choice depends on the requirements of the network.

10. Fiber-Optic Connections

Fiber-optic cables carry information using light through extremely thin strands of glass or plastic.

Fiber is especially useful when a network needs to transmit data over longer distances or at high speeds.

Fiber connections are commonly encountered in:

  • Data centers
  • Telecommunications networks
  • ISP infrastructure
  • Building-to-building connections
  • High-speed network backbones
Remember:

Fiber is not simply a "faster Ethernet cable." Ethernet is a networking technology, while fiber is a physical medium that can carry network signals.

11. Wi-Fi Connections

Wi-Fi allows devices to communicate over a wireless radio connection.

Instead of plugging an Ethernet cable directly into a laptop, the laptop can connect to a wireless access point.

Laptop → Wi-Fi → Access Point

The access point can then connect to the wired network using Ethernet.

This creates a mixed network where the connection is wireless between the client and access point but wired between the access point and the rest of the infrastructure.

12. SSID

When connecting to Wi-Fi, you normally choose a wireless network name from the available networks.

This name is called the SSID, which stands for Service Set Identifier.

For example, a school might have a Wi-Fi network called:

Kirinyaga University Wi-Fi

A device uses the wireless network information and security credentials to establish a connection with the wireless network.

Do not confuse SSID with a password.

The SSID identifies the wireless network. The password is used to authenticate a user or device when security is enabled.

13. Link and Activity Lights

Physical network equipment often has small LEDs near its ports.

These lights can provide useful information about the state of a connection.

Depending on the device, the lights may indicate things such as:

  • Whether a physical link has been established
  • Whether data is being transmitted
  • The negotiated connection speed
  • Whether the port is active
Troubleshooting example:

If a computer is connected to a switch but there is no link light, I would start by checking the cable, connectors, ports and network interface.

14. What Happens When I Plug in an Ethernet Cable?

Plugging in an Ethernet cable is more than simply creating a physical connection.

At a simplified level:

  1. The cable physically connects the two interfaces.
  2. The interfaces detect that a physical connection exists.
  3. The devices negotiate characteristics such as link speed and duplex settings.
  4. A link may become active, which can be shown by a link light.
  5. Higher-level network communication can then take place once the devices are appropriately configured.
Important:

A physical link does not automatically mean that the device has Internet access.

A cable can be connected correctly while the device still has an IP addressing, configuration, routing or other networking problem.

15. Physical Connection vs Network Configuration

This is an important distinction to understand before moving further into networking.

Physical Connection

The physical connection is concerned with things such as:

  • Cables
  • Ports
  • Connectors
  • NICs
  • Wireless radio connections
  • Link status

Logical Configuration

Logical networking is concerned with things such as:

  • IP addresses
  • Subnet masks
  • Default gateways
  • DNS settings
  • VLANs
  • Routing
Example:

A computer can have a perfectly good Ethernet cable and an active link but still fail to communicate because its IP configuration is incorrect.

We will build on this distinction as we move into later networking topics.

17. Putting the Connections Together

Now I can look at a simple network and identify the different types of connections involved.

Laptop → Wi-Fi → Access Point → Ethernet → Switch → Ethernet → Router → Internet

There are several different things happening here:

  1. The laptop uses its wireless NIC to communicate over Wi-Fi.
  2. The access point receives the wireless communication.
  3. The access point is physically connected to the switch using Ethernet.
  4. The switch forwards traffic toward the router.
  5. The router connects the local network to another network.

This is the kind of network path I will eventually build and test in Packet Tracer.

18. What to Remember

  • A device needs a network interface to communicate on a network.
  • Physical network ports provide places to connect cables.
  • Ethernet is widely used for wired local networks.
  • RJ-45 is the common name used for the connector found on many twisted-pair Ethernet cables.
  • Copper and fiber are two important wired transmission media.
  • Wi-Fi provides wireless connectivity.
  • T568A and T568B define different wire arrangements for twisted-pair Ethernet cabling.
  • Straight-through and crossover describe different wiring arrangements.
  • Modern devices often support auto-MDI/MDIX, reducing the need to manually choose between cable types.
  • A physical link does not automatically mean that the network is correctly configured.
  • Physical connections and logical network configuration are related but different concepts.
