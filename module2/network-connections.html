Network Connections

In the previous topic, I learned about the main components that make up a network. Now I want to understand how these components are actually connected to each other.

Network connections can be wired or wireless. Different types of cables, ports, wireless technologies and network devices work together to create communication between devices.

1. What Is a Network Connection?

A network connection is a communication link that allows two or more devices to exchange data.

The connection can use a physical medium, such as an Ethernet cable or fiber-optic cable, or it can use a wireless signal such as Wi-Fi.

Simple definition:

A network connection is the path through which devices communicate and exchange data.

For example, when a laptop is connected to a switch using an Ethernet cable, the cable provides the physical connection between the laptop's network interface and the switch port.

2. Wired Connections

A wired network connection uses a physical cable to carry data between devices.

Wired connections are common in offices, schools, data centers and other environments where reliable and consistent network connectivity is important.

Common wired media include:

  • Twisted-pair Ethernet cables
  • Fiber-optic cables
  • Coaxial cables
Think about your laptop:

If you connect your laptop to a network using an Ethernet cable, the cable carries the network signals between your laptop and the device on the other end.

3. Ethernet Connections

Ethernet is one of the most common technologies used for wired local area networks.

Ethernet commonly uses twisted-pair cables with connectors that plug into Ethernet ports on network devices.

For example, an Ethernet cable can connect:

  • A computer to a switch
  • A switch to a router
  • An access point to a switch
  • A server to a switch
  • A printer to a switch
Basic example:

Laptop → Ethernet Cable → Switch

The Ethernet cable is the physical medium, while the Ethernet technology defines how data is transmitted across that connection.

4. Network Ports

A network port is a physical interface on a device where a network cable can be connected.

For example, a switch normally has multiple Ethernet ports. Each port can be used to connect another device or network component.

Do not confuse these two:

A physical network port is where a cable is plugged into a device. A logical port, such as TCP port 80 or TCP port 443, is used by network protocols and applications.

At this stage, when we talk about connecting devices, we are mainly referring to the physical network ports.

5. Fiber-Optic Connections

Fiber-optic cables transmit data using pulses of light through optical fiber.

Fiber is commonly used where high bandwidth, long distances or resistance to electromagnetic interference are important.

For example, fiber can be used to connect network equipment between buildings or to connect parts of a large network.

Simple comparison:

Copper Ethernet uses electrical signals, while fiber uses light to carry information.

6. Wireless Connections

A wireless connection allows devices to communicate without using a physical cable for that part of the connection.

Wi-Fi is the most familiar example of a wireless network technology.

A laptop, smartphone or tablet can connect wirelessly to a wireless access point.

Basic example:

Smartphone → Wi-Fi → Access Point

The access point can then connect to the wired network using Ethernet.

This means a network can contain both wireless and wired connections at the same time.

7. How Wired and Wireless Connections Work Together

Real networks often combine wired and wireless connections instead of choosing only one.

Imagine a university network. Students might use Wi-Fi on their laptops and phones, while servers, switches and access points may be connected using Ethernet or fiber.

Laptop → Wi-Fi → Access Point → Ethernet → Switch → Router → Internet

The first part of the journey is wireless, but the rest of the path can be wired.

This is an important idea because a Wi-Fi network is still usually connected to a larger wired network infrastructure.

8. Connecting End Devices to a Switch

One of the most common network connections is an end device connected to a switch.

For example, a computer in a computer laboratory can connect to a switch using an Ethernet cable.

Computer → Ethernet Cable → Switch

The computer's NIC provides the network interface, while the Ethernet cable provides the physical connection to the switch.

The switch can then provide connectivity to other devices on the local network.

9. Connecting Switches Together

A network can contain more devices than a single switch can accommodate. Multiple switches can therefore be connected together.

Devices → Switch 1 → Switch 2 → More Devices

Connecting switches together allows devices connected to different switches to communicate as part of the same network, subject to the network's configuration.

Larger networks can have many switches arranged in different designs depending on the organization's requirements.

10. Connecting a Switch to a Router

A switch and router can be connected together so that devices on the local network can communicate with other networks.

Computer → Switch → Router → Other Network

The switch provides connectivity within the local network, while the router provides a path to another network.

In a home network, for example, the router provided by an Internet service provider can connect the local network to the Internet.

11. Connecting an Access Point to a Network

A wireless access point can connect to a switch using an Ethernet cable.

Wireless devices then communicate with the access point over Wi-Fi.

Laptop → Wi-Fi → Access Point → Ethernet → Switch

This is how a wireless device can become part of a larger wired network.

12. Common Network Connections

Connection Typical Medium Purpose
Computer → Switch Ethernet cable Connect an end device to a local network
Server → Switch Ethernet or fiber Connect a server to the network
Access Point → Switch Ethernet Connect wireless users to the wired network
Switch → Switch Ethernet or fiber Expand the network
Switch → Router Ethernet or fiber Connect the local network to another network
Laptop → Access Point Wi-Fi Provide wireless network access

13. How Connections Form a Network

Once several devices are connected, the arrangement of those connections forms a network topology.

A topology describes how devices and connections are arranged.

Some common network topologies include:

  • Star topology
  • Bus topology
  • Ring topology
  • Mesh topology
  • Hybrid topology

In modern Ethernet LANs, a star-like arrangement around switches is very common.

Important:

A topology describes the arrangement of connections. It does not simply mean the type of cable being used.

14. Following a Connection

One useful networking skill is learning how to follow the path that data takes between two devices.

Consider this simplified example:

Laptop → Wi-Fi → Access Point → Ethernet → Switch → Ethernet → Router → Internet

Instead of seeing this as one complicated network, I can break it into individual connections:

  1. The laptop connects wirelessly to the access point.
  2. The access point connects to the switch using Ethernet.
  3. The switch forwards traffic toward the router.
  4. The router forwards traffic toward another network.

Being able to follow this path will become very useful when working with Packet Tracer later.

15. What to Remember

  • A network connection provides a path for devices to communicate.
  • Connections can be wired or wireless.
  • Ethernet is commonly used for wired local network connections.
  • Fiber-optic connections use light to transmit data.
  • Wi-Fi provides wireless connectivity.
  • An access point can connect wireless devices to a wired network.
  • Switches can connect to other switches to expand a network.
  • A switch can connect a local network to a router.
  • Following the connection path helps explain how data moves through a network.
