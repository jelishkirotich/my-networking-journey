Network Components

A computer network is made up of different devices and components that work together to allow computers and other devices to communicate.

In this topic, I am learning about the main components found in a network, what each one does, and how they work together. Understanding these components will make it easier to understand the connections and network configurations that come later in this module.

1. What Are Network Components?

Network components are the physical devices and technologies that allow devices to connect, communicate, and exchange information over a network.

Some components are devices that we can physically see, such as switches, routers and wireless access points. Others are part of the devices themselves, such as a Network Interface Card (NIC).

Simple definition:

Network components are the parts that help devices connect to a network and communicate with other devices or networks.

Examples of common components used in computer networks.

2. End Devices

End devices are the devices at the edge of a network where communication begins or ends.

These are usually the devices that people use to access network services or communicate with other devices.

Examples include:

  • Desktop computers
  • Laptops
  • Smartphones
  • Tablets
  • Network printers
  • IP phones
  • Servers
  • IoT devices such as cameras and sensors
Think of it this way:

If I use my laptop to open a website, my laptop is an end device. The communication starts from my laptop and eventually returns to it.

3. Network Interface Card (NIC)

A Network Interface Card, commonly called a NIC, is the component that allows a device to connect to a network.

A NIC can provide either a wired or wireless network connection.

  • An Ethernet NIC allows a device to connect using a network cable.
  • A wireless NIC allows a device to connect using Wi-Fi.

Modern laptops and smartphones usually have wireless network interfaces built into the device. Desktop computers can have both wired Ethernet and wireless connectivity.

Important:

A NIC gives a device a way to communicate on a network. A network interface is also associated with a MAC address, which is used for communication on a local Ethernet or wireless network.

The MAC address is different from an IP address. The MAC address identifies the network interface, while an IP address identifies the device's network connection.

4. Network Switch

A network switch connects multiple devices on the same local network.

For example, a switch can connect computers, printers, servers and wireless access points within an office or school.

A network switch provides multiple connections for devices on a local network.

When data arrives at a switch, the switch uses information about connected devices to determine where the Ethernet frame should be forwarded.

Simple way to remember a switch:

A switch mainly connects devices within the same local network.

There are different types of switches. An unmanaged switch generally works with little or no configuration, while a managed switch provides more control and configuration options.

5. Router

A router connects different networks together.

For example, a router can connect a local network in a home, school or organization to another network such as the Internet.

A router connects different networks and forwards traffic between them.

Routers make forwarding decisions using network information, particularly IP addressing and routing information.

Simple definition:

A router is a device that connects different networks and forwards packets between those networks.

This is one of the important differences between a switch and a router. A switch primarily connects devices within a local network, while a router connects different networks.

6. Wireless Access Point

A wireless access point, commonly called an AP, allows wireless devices to connect to a network using Wi-Fi.

A wireless access point provides Wi-Fi connectivity to wireless devices.

For example, when a laptop connects to the Wi-Fi in a school, the laptop can communicate wirelessly with an access point.

The access point is normally connected to the rest of the network using a wired connection.

Important idea:

The connection between the wireless device and the access point is wireless, but the access point can then connect into the wired network through Ethernet.

This means that Wi-Fi does not mean that the entire network is wireless. In many networks, wireless devices communicate with an access point, and the access point connects to switches and other wired infrastructure.

7. Server

A server is a computer or system that provides services, resources or information to other devices on a network.

The devices requesting these services are usually called clients.

Examples of servers include:

  • Web servers
  • File servers
  • Database servers
  • DNS servers
  • Email servers
  • Application servers

Servers provide resources and services to other devices.

Example:

When I open a website, my computer acts as a client and requests information from a web server. The server processes the request and sends the required information back.

We will look at the relationship between clients and servers in more detail later in this module.

8. Firewall

A firewall is a security system that controls network traffic according to defined security rules.

It can examine traffic entering or leaving a network and determine whether that traffic should be allowed or blocked.

A firewall can exist as dedicated hardware, software, or as a security function built into another network device.

Simple definition:

A firewall acts as a security barrier that controls network traffic based on rules.

Do not confuse a firewall with a router.

A router's main role is connecting networks and forwarding traffic. A firewall's main role is controlling traffic according to security policies. Some modern routers can also include firewall functionality.

9. Network Media

Network media refers to the physical or wireless method used to carry data from one network device to another.

Common examples include:

  • Twisted-pair Ethernet cables
  • Fiber-optic cables
  • Coaxial cables
  • Wi-Fi radio signals
  • Cellular wireless connections

Network cables are examples of wired transmission media.

Twisted-Pair Ethernet

Twisted-pair Ethernet cables are commonly used to connect computers, switches, routers, access points and other network devices.

Fiber Optic

Fiber-optic cables transmit data using light. They are useful for high-speed connections and longer distances.

Wireless

Wireless networks use radio waves instead of a physical cable for the wireless portion of the connection.

The choice of network media depends on factors such as distance, speed, environment and the requirements of the network.

10. Switch vs Router

Switches and routers are both important network devices, but they perform different main functions.

Feature Switch Router
Main purpose Connects devices on a local network Connects different networks
Common address information MAC addresses IP addresses
Typical role Connects computers, printers and servers Connects a LAN to other networks
Example Connects computers in a school lab Connects the school network to the Internet

In real networks, the distinction can become more complicated because modern switches can include Layer 3 routing functionality. For now, the important beginner concept is: switches connect devices within a network, while routers connect networks.

11. How the Components Work Together

The individual components become more useful when we look at how they work together as one network.

Imagine that a laptop is connected to Wi-Fi in a school. A simplified path could look like this:

Laptop → Wireless Access Point → Switch → Router → Internet

A simplified example of how common network components can work together.

Here is what happens at a basic level:

  1. The laptop connects to the network through its wireless NIC.
  2. The wireless connection reaches the access point.
  3. The access point connects the wireless device to the network infrastructure.
  4. The switch connects devices within the local network.
  5. The router connects the local network to another network, such as the Internet.
  6. The requested data travels through the appropriate network components until it reaches its destination.
This is the big picture.

A network is not just one device. Different components have different jobs, and they work together to provide communication and network services.

12. What to Remember

  • End devices are devices where network communication begins or ends.
  • A NIC gives a device a network interface so it can communicate on a network.
  • A switch connects multiple devices on a local network.
  • A router connects different networks.
  • A wireless access point allows wireless devices to connect to a network.
  • A server provides services or resources to other devices.
  • A firewall controls network traffic according to security rules.
  • Network media carries data through wired or wireless connections.
  • Network components work together rather than operating independently.
