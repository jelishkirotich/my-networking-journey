MODULE 8

IPv4 Address Structure

Understanding the 32-bit structure of an IPv4 address, octets, binary values, and dotted-decimal notation.

Understanding the Structure of an IPv4 Address

In the previous topic, we learned that an IPv4 address is 32 bits long.

Those 32 bits are divided into four groups of 8 bits. Each group is called an octet.

IPv4 addresses are normally written in dotted-decimal notation. This makes the address much easier for humans to read than a long string of binary numbers.

Basic Structure

192 . 168 . 1 . 10
 |     |    |    |
Octet Octet Octet Octet
  1     2    3    4

IPv4 Contains 32 Bits

A bit is a binary digit. It can have only one of two values:

0

A binary position that is turned off.

1

A binary position that is turned on.

Since an IPv4 address contains 32 bits, its complete binary representation contains 32 zeros and ones.

11000000101010000000000100001010

Reading all 32 bits at once is difficult for humans, so IPv4 divides them into four groups of eight.

11000000 . 10101000 . 00000001 . 00001010

What Is an Octet?

An octet is simply a group of 8 bits.

Since an IPv4 address contains 32 bits:

32 bits ÷ 8 bits = 4 octets

Therefore, every IPv4 address contains exactly four octets.

Octet Number of Bits
Octet 1 8 bits
Octet 2 8 bits
Octet 3 8 bits
Octet 4 8 bits
Total 32 bits

Understanding the 8 Binary Positions

Each octet contains eight positions. Each position represents a power of 2.

Position 128 64 32 16 8 4 2 1
Bit 2⁷ 2⁶ 2⁵ 2⁴ 2³ 2² 2¹ 2⁰

The values are obtained from powers of two:

128 + 64 + 32 + 16 + 8 + 4 + 2 + 1

When the bits are combined, the largest possible value of one octet is:

128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255

This is why each IPv4 octet can contain a decimal value from 0 to 255.

Converting Binary to Decimal

Let's take one octet and convert it from binary to decimal.

11000000

Place the binary value over the corresponding powers of two:

Bit 1 1 0 0 0 0 0 0
Value 128 64 32 16 8 4 2 1

The two 1s mean that we use 128 and 64:

128 + 64 = 192

Therefore:

11000000 = 192

We can use the same process for every octet.

Complete IPv4 Example

Let's convert:

192.168.1.10

Its binary representation is:

11000000.10101000.00000001.00001010
Octet Decimal Binary
1 192 11000000
2 168 10101000
3 1 00000001
4 10 00001010

The four binary octets together contain exactly 32 bits.

What Is Dotted-Decimal Notation?

The binary representation of an IPv4 address is useful for computers, but it is not convenient for people to read.

Instead, each 8-bit octet is converted into a decimal number and the four numbers are separated by dots. 

Binary:

11000000 . 10101000 . 00000001 . 00001010

             ↓

Decimal:

   192    .    168    .     1     .    10

Therefore:

11000000.10101000.00000001.00001010

becomes

192.168.1.10

Valid and Invalid IPv4 Addresses

Because each octet can only contain a value from 0 to 255, we can use this rule to quickly identify some invalid IPv4 addresses.

Address Valid? Reason
192.168.1.10 Yes All octets are between 0 and 255.
10.0.0.1 Yes All octets are between 0 and 255.
172.16.25.250 Yes All octets are between 0 and 255.
192.168.1.300 No 300 is greater than 255.
10.500.1.2 No 500 is greater than 255.

This only checks whether the notation is numerically valid. It does not mean that every numerically valid address can be assigned to a particular host. Special addresses and network configuration rules also exist.

A Preview: Network and Host Portions

An IPv4 address does more than identify a device. It also contains information about the network to which the device belongs.

An IPv4 address is divided into a network portion and a host portion. The subnet mask or prefix determines where that boundary occurs.

For example, with:

192.168.1.10/24

the /24 indicates that the first 24 bits belong to the network prefix, leaving 8 bits for the host portion. 

192.168.1.10/24

Network portion        Host portion
--------------------   ------------
192.168.1              10

We will study this carefully in the next topic instead of trying to understand the entire idea at once.

Do Not Confuse These Terms

Term Meaning
Bit A binary digit with a value of 0 or 1.
Octet A group of 8 bits.
IPv4 Address A 32-bit logical address represented as four octets.
Dotted Decimal The human-readable way IPv4 addresses are normally written, such as 192.168.1.10.
Subnet Mask / Prefix Information that determines which bits belong to the network portion and which belong to the host portion.

Quick Notes

  • IPv4 addresses contain 32 bits.
  • 32 bits are divided into four octets.
  • Each octet contains 8 bits.
  • Each octet can have a decimal value from 0 to 255.
  • IPv4 is normally written in dotted-decimal notation.
  • Example: 192.168.1.10
  • Binary example: 11000000.10101000.00000001.00001010
  • A subnet mask or prefix determines the boundary between network and host portions.
