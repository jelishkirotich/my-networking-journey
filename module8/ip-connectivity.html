IP Connectivity

Understanding how devices use IPv4 addresses, subnet information, default gateways, and routers to communicate.

What Is IP Connectivity?

IP connectivity means the ability of devices to communicate with each other using Internet Protocol (IP).

In the previous topics, we learned that every IPv4 address contains information about a network and a host.

Now we are going to put those ideas together and answer an important question:

How does a computer know where to send an IP packet?

It uses the destination IP address, its own network information, and routing information to decide where the packet should go.

The Basic Communication Process

Imagine that PC0 wants to send data to PC1. 

PC0
IP: 192.168.1.10/24

        ↓

PC1
IP: 192.168.1.20/24

Before sending the packet, PC0 needs to determine whether PC1 is on the same IP network.

PC0 compares the network information of its own address with the network information of the destination.

Both addresses belong to: 

192.168.1.0/24

Therefore, PC0 knows that PC1 is on the same IP network.

Same-Network Communication

Let's look at the example more visually. 

        SAME IP NETWORK
       192.168.1.0/24

   PC0                         PC1
192.168.1.10              192.168.1.20
      |                         |
      |                         |
      +-------- Switch ---------+

Both computers are members of the same IP network.

The switch provides the local Ethernet connection between the devices.

Remember from Module 7 that Ethernet uses MAC addresses for local frame delivery. IP operates at a higher layer and provides logical addressing.

Think of the two addresses differently

IP address: Helps identify the source and destination at the network layer.

MAC address: Used for local Ethernet frame delivery.

Different-Network Communication

Now let's change the destination. 

PC0:
192.168.1.10/24

Destination:
192.168.2.10/24

PC0 determines that the destination belongs to a different network.

The two networks are:

PC0 192.168.1.10/24 192.168.1.0/24
PC1 192.168.2.10/24 192.168.2.0/24

Because the destination is on another network, PC0 needs to send the packet toward a router.

What Is a Default Gateway?

A default gateway is the device that a host sends traffic to when the destination is outside the host's local network.

In many networks, the default gateway is the IP address of a router interface on the same local network as the host.

For example: 

PC0 IP address:       192.168.1.10
Subnet mask:          255.255.255.0
Default gateway:      192.168.1.1

Here, the router's interface might have the address: 

192.168.1.1

This router interface is reachable from PC0's local network and can provide a path toward other networks.

Simple definition

The default gateway is the device a host uses to reach destinations outside its own IP network.

Same Network or Different Network?

Let's make the decision process simple.

Question Result
Is the destination on the same IP network? Send the traffic through the local network.
Is the destination on another IP network? Send the traffic toward the default gateway/router.

The subnet mask or prefix length helps the host determine the network boundary.

Complete Example

Let's follow a packet from PC0 to PC1. 

PC0
IP address:     192.168.1.10
Subnet mask:    255.255.255.0
Default gateway:192.168.1.1

Destination:
192.168.2.10

Step 1: PC0 Creates the Packet

PC0 has data that needs to be sent to the destination.

The IP packet contains source and destination IP information. 

Source IP:       192.168.1.10
Destination IP:  192.168.2.10

Step 2: PC0 Checks the Destination Network

PC0 uses its subnet information to determine whether 192.168.2.10 belongs to the same network.

PC0 belongs to: 

192.168.1.0/24

The destination belongs to: 

192.168.2.0/24

These are different networks.

Step 3: PC0 Uses the Default Gateway

PC0 sends the traffic toward its default gateway: 

192.168.1.1

Step 4: The Router Receives the Packet

The router examines the destination IP address and uses its routing information to determine where the packet should go next.

Step 5: The Packet Is Forwarded

The router forwards the packet toward the network containing 192.168.2.10.

Step 6: The Destination Receives the Data

Eventually, the packet reaches the network containing PC1, and the data can be delivered to the destination device.

What Does the Router Look At?

A router needs to make forwarding decisions.

One important piece of information it examines is the destination IP address.

The router then looks at its routing information to determine where the packet should be forwarded.

Cisco documentation describes routers using routing tables and route selection to determine the next hop for IPv4 traffic. When multiple routes match, the longest matching prefix is preferred.

For now, remember

A router's job is to connect different networks and make forwarding decisions about where packets should go.

IP Address vs Default Gateway

These two values are related, but they are not the same thing.

Value Purpose Example
IP address Identifies the host/interface on its IP network. 192.168.1.10
Subnet mask Defines the network and host portions. 255.255.255.0
Default gateway Provides the next step toward other networks. 192.168.1.1

What If There Is No Default Gateway?

A device can still communicate with devices on its local IP network without needing to send that traffic through a default gateway.

However, communication with destinations on other networks normally requires a route toward those networks.

Local destination: communication can remain on the local network.

Remote destination: the device needs a path toward the other network.

This is why a correctly configured host commonly has an IP address, subnet mask or prefix, and default gateway.

IP Connectivity and MAC Addresses

It is important not to think of IP and MAC addresses as competing systems.

They work together.

Layer Address Main Role
Network Layer IP address Logical addressing and communication between IP networks.
Data Link Layer MAC address Local delivery of Ethernet frames.

This connects directly to Module 7.

IP helps determine the logical destination, while Ethernet and MAC addressing are involved in delivering frames across the local link.

Module 8 Summary

In this module, we started with the Internet Protocol and then moved into IPv4 addressing and connectivity.

Internet Protocol

IP provides logical addressing and helps packets move between networks.

IPv4

IPv4 uses 32-bit logical addresses written as four decimal octets.

Network Portion

Identifies the IP network to which an address belongs.

Host Portion

Identifies a device or interface within the network.

Subnet Mask

Separates the network portion from the host portion.

IP Connectivity

Devices use network information and routing to determine how packets should reach their destinations.

Quick Notes

IP: Internet Protocol provides logical addressing and packet delivery between networks.

IPv4: Uses 32-bit addresses.

Network portion: Identifies the network.

Host portion: Identifies the device/interface within the network.

Subnet mask: Determines the boundary between network and host portions.

/24: 24 network bits and 8 host bits.

Default gateway: The device a host normally uses to reach destinations outside its local network.

Router: Connects IP networks and forwards packets toward destinations.

Same network: Traffic can remain within the local network.

Different network: Traffic needs a route toward the destination network.

The big picture

An IP address tells us about a device's logical location. The subnet information tells us which network it belongs to. The device uses this information to decide whether the destination is local or remote. If the destination is remote, traffic can be sent toward a router/default gateway.
