MODULE 8

Network and Host Portions

Understanding how an IPv4 address identifies both a network and a device within that network.

What Are Network and Host Portions?

An IPv4 address does more than simply give a device a number. It contains information that helps identify:

  • The network where the device is located.
  • The host or interface within that network.

This is why an IPv4 address can be thought of as having two important parts: a network portion and a host portion.

Simple idea

The network portion tells us which network the device belongs to, while the host portion helps identify the particular device or interface within that network.

Why Do We Need These Two Portions?

Imagine a university with several departments. Each department could have its own network.

For example:

  • Software Engineering network
  • Business network
  • Computer Science network

If a computer wants to communicate with another device, the network needs to determine whether the destination is on the same network or somewhere else.

The network portion helps answer:

Question

"Which network does this IP address belong to?"

The host portion helps answer:

Question

"Which particular device or interface is this?"

The Subnet Mask

Now we need a way to tell which part of an IPv4 address is the network portion and which part is the host portion.

This is where the subnet mask comes in.

A subnet mask tells a device which bits of an IPv4 address represent the network portion and which bits represent the host portion.

A subnet mask can be written in dotted-decimal form, such as: 

255.255.255.0

It can also be written using prefix notation: 

/24

These two notations represent the same mask:

Notation Example
Dotted-decimal 255.255.255.0
Prefix length /24

What Does /24 Mean?

This is one of the most important things to understand.

An IPv4 address contains 32 bits.

When we write /24, the number 24 tells us that the first 24 bits are the network portion.

That leaves:

32 total bits

24 network bits

8 host bits

Therefore: 

/24 = 24 network bits + 8 host bits

Cisco describes the prefix length as the number of high-order bits that make up the network portion of the address.

Example: 192.168.1.10/24

Let's use a complete example: 

IP address: 192.168.1.10/24

The /24 tells us that the first 24 bits belong to the network portion.

The equivalent subnet mask is: 

255.255.255.0

We can visualize the address like this: 

192       .168       .1        .10
|          |         |          |
----------- NETWORK  -----------
                              HOST

With a /24 prefix, the first three octets represent the network portion, while the final octet represents the host portion.

Looking at It in Binary

Remember from the previous topic that an IPv4 address contains 32 binary bits.

The address: 

192.168.1.10

can be written in binary as: 

11000000.10101000.00000001.00001010

The /24 subnet mask is: 

11111111.11111111.11111111.00000000

The first 24 bits are the network bits, while the final 8 bits are the host bits. 

IP Address:
11000000.10101000.00000001.00001010
|-----------------------|--------|
       NETWORK             HOST
          24 bits           8 bits

Subnet Mask:
11111111.11111111.11111111.00000000
|-----------------------|--------|
       NETWORK             HOST
          24 bits           8 bits

Finding the Network Address

Once we know the network portion, we can determine the network address.

Consider: 

IP address:    192.168.1.10
Subnet mask:   255.255.255.0
Prefix:        /24

The first 24 bits remain as they are. The host bits are changed to zero to identify the network. 

Network address: 192.168.1.0

So:

192.168.1.10/24

belongs to the network

192.168.1.0/24

The network address identifies the network itself rather than a normal host interface.

Several Devices on the Same Network

Suppose we have three computers:

Device IPv4 Address Prefix Network Host Portion
PC0 192.168.1.10 /24 192.168.1.0 10
PC1 192.168.1.20 /24 192.168.1.0 20
PC2 192.168.1.30 /24 192.168.1.0 30

All three devices have the same network portion: 

192.168.1

But their host portions are different: 

PC0 → 10
PC1 → 20
PC2 → 30

Therefore, they belong to the same 192.168.1.0/24 IP network but have different host addresses.

What If the Network Portion Is Different?

Now consider another computer: 

PC3: 192.168.2.10/24

Its network address is: 

192.168.2.0/24

Compare the two networks:

Device IP Address Network
PC0 192.168.1.10/24 192.168.1.0/24
PC3 192.168.2.10/24 192.168.2.0/24

These are different IP networks because their network portions are different.

Important

Two devices can have valid IPv4 addresses but still belong to different IP networks. The subnet mask or prefix length helps determine the network boundary.

Network Address, Host Addresses and Broadcast Address

For a typical IPv4 /24 network, the addresses have different roles.

For example:

Address Purpose
192.168.1.0 Network address
192.168.1.1 – 192.168.1.254 Typical host address range
192.168.1.255 Broadcast address

The network address represents the network itself. The addresses between the network and broadcast addresses are normally available for host interfaces.

The broadcast address is used to represent all hosts on that particular IPv4 subnet.

Cisco documentation describes the all-zero host portion as the network address and the all-one host portion as the broadcast address for a subnet.

Do not memorize only the numbers

The important idea is that the subnet mask determines where the network portion ends and the host portion begins. Different prefix lengths create different network sizes.

How Does a Device Know If Another Device Is Local?

Suppose PC0 wants to communicate with PC1. 

PC0: 192.168.1.10/24
PC1: 192.168.1.20/24

PC0 compares the network portion of its own address with the network portion of PC1's address.

Both belong to: 

192.168.1.0/24

Therefore, PC0 knows that PC1 is on the same IP network.

In a typical Ethernet LAN, the devices can then communicate directly through the local network without sending the traffic to a router for another IP network.

What Happens When the Destination Is on Another Network?

Now imagine: 

PC0: 192.168.1.10/24

Destination:
192.168.2.10/24

PC0 determines that the destination belongs to a different network.

The traffic therefore needs to be sent toward a router so it can be forwarded toward the destination network. 

192.168.1.0/24                         192.168.2.0/24

    PC0 -------- Switch -------- Router -------- Switch -------- PC3
192.168.1.10                  Default Gateway              192.168.2.10

The router connects different IP networks and can forward packets between them.

We will study this more carefully in the next topic: IP Connectivity.

Subnet Mask and Prefix Length: Quick Reference

Prefix Subnet Mask Network Bits Host Bits
/8 255.0.0.0 8 24
/16 255.255.0.0 16 16
/24 255.255.255.0 24 8
/25 255.255.255.128 25 7
/26 255.255.255.192 26 6

Notice that when the prefix number becomes larger, more bits are used for the network portion and fewer bits remain for hosts.

You do not need to memorize every mask yet. The important thing at this stage is understanding what the prefix length represents.

Key Ideas to Remember

Network Portion

Identifies which IP network the address belongs to.

Host Portion

Identifies a particular device or interface within the network.

Subnet Mask

Defines which bits belong to the network portion and which belong to the host portion.

Prefix Length

The number after the slash, such as /24, tells how many bits belong to the network portion.

Quick Notes

IPv4 address: 32 bits.

Network portion: Identifies the network.

Host portion: Identifies the device/interface within the network.

Subnet mask: Shows where the network portion ends.

/24: 24 network bits + 8 host bits.

255.255.255.0: Same mask as /24.

Network address: Host bits are all 0.

Broadcast address: Host bits are all 1 in a typical IPv4 subnet.

Different network portions: The devices belong to different IP networks.
