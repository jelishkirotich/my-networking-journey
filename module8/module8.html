MODULE 8

Internet Protocol and IPv4

Understanding how IP addresses identify devices and allow communication across networks.

Welcome to Module 8

In the previous modules, we learned how devices connect to a network, how Ethernet communication works, and how switches use MAC addresses to deliver frames.

Now we move to another important part of networking: Internet Protocol (IP).

IP allows devices to be identified logically and helps data move between different networks. In this module, we will concentrate mainly on IPv4, one of the most widely taught versions of the Internet Protocol.

The Big Picture

Imagine that you want to send a package to someone in another town. The delivery system needs an address so that it knows where the package should go.

Networking works in a similar way. Devices use IP addresses as logical addresses that help identify where data should be delivered.

One Important Distinction

Before we begin, remember that MAC addresses and IP addresses are not the same thing.

MAC Address IP Address
Used for communication at the Data Link Layer. Used for logical addressing at the Network Layer.
Example: 00:1A:2B:3C:4D:5E Example: 192.168.1.10
Switches use MAC addresses when forwarding Ethernet frames. Routers use IP addresses when making forwarding decisions between networks.

We will explore this difference in much more detail in the topic pages.
