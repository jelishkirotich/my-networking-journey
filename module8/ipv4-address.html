MODULE 8

IPv4 Address

Understanding the purpose, features, and role of IPv4 addresses in network communication.

What Is an IPv4 Address?

IPv4 stands for Internet Protocol version 4.

An IPv4 address is a logical address used to identify a network interface in an IPv4 network. It provides information that allows IP packets to be sent toward their destination.

An IPv4 address is made up of 32 binary bits. These 32 bits are divided into four groups of 8 bits, called octets. IPv4 addresses are normally written using dotted-decimal notation.

Example IPv4 Address

192.168.1.10

This is a human-readable representation of a 32-bit IPv4 address.

Why Do We Need IPv4 Addresses?

Imagine a network with hundreds or thousands of devices. If there were no logical addressing system, it would be difficult to determine where a packet should be sent.

IPv4 provides logical addresses that allow devices and networking equipment to identify source and destination locations.

Think of an IPv4 address as a logical network address.

It helps answer:

"Which network is this device on, and which device on that network are we trying to reach?"

A Simple Example

Suppose we have three computers connected to the same network: 

                 Network
                    |
        +-----------+-----------+
        |           |           |
       PC0         PC1         PC2
       |            |            |
192.168.1.10  192.168.1.20  192.168.1.30

Each device has its own IPv4 address.

Device IPv4 Address
PC0 192.168.1.10
PC1 192.168.1.20
PC2 192.168.1.30

Notice that the addresses are different. This allows the devices to be distinguished from one another within the network.

IPv4 Addresses Are Assigned to Network Interfaces

An important point is that an IPv4 address is associated with a network interface, rather than simply being a permanent label attached to the entire physical device.

A computer may have more than one network interface. For example, a laptop could have:

  • A wireless network interface
  • A wired Ethernet interface

Each interface can participate in networking and can have its own IP configuration. 

                Laptop
                   |
        +----------+----------+
        |                     |
   Wi-Fi NIC              Ethernet NIC
        |                     |
192.168.1.20           192.168.10.20

This is why networking discussions often refer to an IP address as an interface address.

Main Features of IPv4 Addresses

32 Bits

An IPv4 address contains 32 binary bits.

Four Octets

The 32 bits are divided into four groups of 8 bits each.

Dotted Decimal

IPv4 addresses are normally written as four decimal numbers separated by periods.

Logical Address

IPv4 provides logical addressing at the Network Layer.

Network Identification

Part of the address identifies the network associated with the interface.

Host Identification

Another portion identifies the particular interface within that network.

IPv4 Has 32 Bits

Computers ultimately work with binary values, so an IPv4 address is represented internally using 32 bits.

For example, this IPv4 address:

192.168.1.10

can be represented in binary as:

11000000.10101000.00000001.00001010

There are four groups, and each group contains eight bits:

Octet 1 Octet 2 Octet 3 Octet 4
11000000 10101000 00000001 00001010
192 168 1 10

We will study how this conversion works in much more detail on the next page about IPv4 address structure.

Why Does Each Octet Range From 0 to 255?

Each octet contains 8 bits.

With 8 binary bits, the smallest possible value is:

00000000 = 0

The largest possible value is:

11111111 = 255

Therefore, each IPv4 octet can contain a decimal value from 0 through 255.

Remember:

An IPv4 address has four octets, and every octet must contain a value from 0 to 255.

Breaking Down an Example

Consider:

172.16.25.50
Octet Decimal Value
1st 172
2nd 16
3rd 25
4th 50

These four values together represent one 32-bit IPv4 address.

IPv4 vs IPv6

IPv4 is not the only version of IP. There is also IPv6 (Internet Protocol version 6).

Feature IPv4 IPv6
Address size 32 bits 128 bits
Example notation 192.168.1.10 2001:db8::1
Number system Decimal Hexadecimal
Separator Periods Colons

In this module, we are concentrating on IPv4 because it is the addressing system we are learning in detail.

Important: An IP Address Is Not the Same as a MAC Address

It is easy to confuse these two addresses because both are used during network communication.

IPv4 Address MAC Address
Logical Network Layer address Data Link Layer address
Example: 192.168.1.10 Example: 00:1A:2B:3C:4D:5E
Used for IP communication and routing decisions Used for local Ethernet frame delivery

They work together. An IP packet can be carried inside an Ethernet frame, meaning the communication can involve both an IP address and a MAC address at different layers.

Quick Notes

  • IPv4 means Internet Protocol version 4.
  • An IPv4 address contains 32 bits.
  • The 32 bits are divided into four 8-bit octets.
  • IPv4 is normally written in dotted-decimal notation.
  • Each octet has a value from 0 to 255.
  • An IPv4 address is associated with a network interface.
  • IPv4 provides logical addressing at the Network Layer.
  • Part of an IPv4 address identifies the network and another part identifies the host/interface.
