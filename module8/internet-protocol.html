MODULE 8

Internet Protocol

Understanding how IP provides logical addressing and helps data travel between networks.

What Is Internet Protocol?

Internet Protocol (IP) is a network-layer protocol used to provide logical addressing and help deliver packets from a source to a destination.

In simple terms, IP helps the network answer an important question:

"Where is the destination device, and where should this packet go?"

Every device that communicates using IP needs an IP address associated with its network interface. The IP address provides logical information that allows devices and routers to identify the source and destination of IP packets.

IP operates at Layer 3 (the Network Layer) of the OSI model.

Why Do We Need IP?

Remember that in Module 7 we learned about MAC addresses.

A switch can use MAC addresses to deliver Ethernet frames within a local network. However, when communication needs to travel between different networks, we need logical addressing and routing.

This is where IP becomes important.

MAC Address

Helps identify a network interface for communication on the local data-link network.

IP Address

Provides logical addressing that allows packets to be delivered toward their destination network and host.

Router

Uses destination IP information to make forwarding decisions between networks.

A Simple Example

Imagine that PC0 wants to communicate with PC1.

Example Network

PC0                         PC1
192.168.1.10                192.168.1.20
   |                            |
   |                            |
   +--------- Network ---------+

PC0 has the IP address:

192.168.1.10

PC1 has the IP address:

192.168.1.20

When PC0 creates an IP packet for PC1, the packet contains information about the source and destination IP addresses.

Field Value Meaning
Source IP 192.168.1.10 The device sending the packet
Destination IP 192.168.1.20 The device the packet is intended for

IP Works With Packets

At the Network Layer, data is carried in an IP packet.

When data moves down the networking protocol stack, the Network Layer adds IP information to the data. This gives the network information about where the packet came from and where it needs to go.

Simplified Encapsulation

Application Data
       ↓
Transport Segment
       ↓
IP Packet
       ↓
Ethernet Frame
       ↓
Bits / Signals

We studied this process in more detail in Module 7 when we learned about encapsulation.

IP Provides Logical Addressing

An IP address is called a logical address because it is assigned according to the network structure rather than simply identifying the physical network hardware.

This is different from a MAC address, which is used at the Data Link Layer.

Feature MAC Address IP Address
Layer Data Link Layer Network Layer
Type Physical/data-link identifier Logical address
Used by Switches Routers and hosts
Example 00:1A:2B:3C:4D:5E 192.168.1.10

These addresses work together rather than replacing one another. A packet may use an IP address for Layer 3 communication while the packet is carried inside an Ethernet frame using MAC addresses at Layer 2.

IP Communication Within a Network

When two devices are on the same IP network, they can communicate directly at the IP level without needing a router to move the packet between different networks. 

        Same Network
     192.168.1.0/24

PC0                          PC1
192.168.1.10                 192.168.1.20
   |                             |
   +----------- Switch ----------+

The devices still use Ethernet frames and MAC addresses for local delivery, while IP provides the logical source and destination addresses.

IP Communication Between Networks

IP becomes especially important when the destination is on a different network. 

Network A                         Network B

   PC0                              PC1
192.168.1.10                    192.168.2.20
     |                               |
     |                               |
   Switch                         Switch
     |                               |
     +------ Router -----------------+

PC0 can determine that PC1 is not on the same local network. The packet can therefore be sent toward a router, which examines the destination IP address and determines where to forward the packet next.

This is the basic idea behind routing: moving IP packets from one network toward another network.

Remember: A switch primarily forwards Ethernet frames using Layer 2 information such as MAC addresses. A router makes Layer 3 forwarding decisions using IP information.

Important Characteristics of IP

Logical Addressing

IP provides logical addresses that identify network interfaces and help identify source and destination locations.

Routing

IP addressing allows routers to determine how packets should be forwarded toward destination networks.

Packet-Based Communication

Data is carried across networks in IP packets.

Network-to-Network Communication

IP allows communication to extend beyond a single local network.

Do Not Confuse IP With the Internet

The word Internet and the abbreviation IP are related, but they do not mean the same thing.

Internet Internet Protocol (IP)
A global system of interconnected networks. A protocol used for logical addressing and packet delivery across networks.

Key Ideas to Remember

  • IP operates at Layer 3, the Network Layer.
  • IP provides logical addressing.
  • IP packets contain source and destination IP information.
  • IP allows communication within and between networks.
  • Routers use destination IP information when making Layer 3 forwarding decisions.
  • IP addresses and MAC addresses have different roles but work together during network communication.
