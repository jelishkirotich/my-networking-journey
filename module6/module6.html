Network Media

Learn how data travels across a network through wireless, copper, and fiber-optic media, and how to choose the right medium for different networking situations.

Introduction to Network Media

Every network needs a way for data to travel from one device to another. The pathway used to carry this data is called network media.

Network media can be a physical cable or a wireless communication path. Different types of media transmit data in different ways and have different advantages and limitations.

The three major types of network media are copper, fiber-optic, and wireless.

The Three Types of Network Media

  • Copper: Transmits data using electrical signals.
  • Fiber-optic: Transmits data using pulses of light.
  • Wireless: Transmits data using electromagnetic waves.

How Data Travels

Although all three types of media are used to carry network data, they do not carry the data in the same physical form.

The three major network media types and the form of signal used by each.

Choosing Network Media

There is no single type of network media that is suitable for every situation. Network engineers choose media according to the requirements of the network.

Some of the important factors considered when selecting network media include:

Distance

How far the signal needs to travel can determine whether copper, fiber, or wireless is appropriate.

Speed & Bandwidth

Networks that need to transfer large amounts of data may require media capable of supporting high bandwidth.

Environment

The physical environment can affect the performance and suitability of different types of media.

Interference

Electrical and electromagnetic interference can affect some types of transmission media.

Cost

The cost of the cable, connectors, equipment, and installation must also be considered.

Reliability

The selected medium should provide a reliable connection for the intended network environment.

Key Idea to Remember

Network media is the pathway through which data travels between network devices.

Copper uses electrical signals, fiber-optic cable uses light, and wireless communication uses electromagnetic waves.
