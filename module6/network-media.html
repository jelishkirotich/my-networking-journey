Network Media

Understanding the different pathways used to carry data across a network.

What Is Network Media?

When two devices communicate over a network, the data needs a pathway through which it can travel. This pathway is known as network media.

Network media can either be a physical medium, such as a copper or fiber-optic cable, or a wireless medium where data travels through the air.

The type of media used in a network affects the distance, speed, reliability, cost, and resistance to interference of the connection.

Simple Definition

Network media is the pathway through which data travels from one network device to another.

The Three Major Types of Network Media

Network media can be grouped into three major categories: wireless media, copper media, and fiber-optic media.

The three major types of network media and how they carry network data.

Wireless Media

Wireless communication sends data through the air using electromagnetic waves.

Wi-Fi, Bluetooth, and cellular networks are examples of wireless communication.

Copper Media

Copper cables transmit data using electrical signals.

UTP Ethernet cables are widely used for wired local area networks.

Fiber-Optic Media

Fiber-optic cables transmit data using pulses of light.

Fiber is commonly used for high-bandwidth and long-distance network connections.

1. Wireless Media

Wireless media allows devices to communicate without requiring a physical cable between them.

Instead of travelling through a cable, the signal travels through space as an electromagnetic wave.

A common example is Wi-Fi. When a laptop connects to a wireless router, the laptop and router exchange information using radio waves.

Examples of Wireless Media

  • Wi-Fi
  • Bluetooth
  • Cellular networks
  • NFC

Advantages of Wireless Media

  • Allows users to move while remaining connected.
  • Does not require a physical cable for every device.
  • Useful for mobile devices such as phones and laptops.
  • Can be convenient to deploy in some environments.

Limitations of Wireless Media

  • Signals can experience interference.
  • Walls and other obstacles can affect signal strength.
  • Coverage depends on the technology and environment.
  • Wireless networks need appropriate security.

2. Copper Media

Copper media uses metal conductors to carry electrical signals representing network data.

Copper is widely used in local area networks because copper Ethernet cables are relatively affordable, flexible, and straightforward to install.

Common copper cable types include coaxial cable and twisted-pair cable.

How Copper Carries Data

Network devices convert digital information into electrical signals that can travel through the copper conductors. The receiving device then interprets those signals as data.

Remember

Copper → electrical signals

3. Fiber-Optic Media

Fiber-optic media uses thin strands of glass or plastic to transmit information using light.

The data is converted into optical signals, which travel through the fiber as pulses of light.

Because the signal is carried as light rather than an electrical current, fiber has important advantages in environments where electromagnetic interference is a concern.

Remember

Fiber → light pulses

Criteria for Choosing Network Media

A network engineer must consider several factors before choosing the media to use for a connection.

Important factors to consider when selecting network media.

1. Distance

The required transmission distance is an important factor. A cable that works well for a short connection may not be suitable for a connection covering a much greater distance.

2. Bandwidth and Speed

The network should use media capable of supporting the required amount of data. Networks that transfer large amounts of information may require high-bandwidth media.

3. Cost

Cost includes the media itself as well as connectors, installation tools, network equipment, and maintenance.

4. Electromagnetic Interference

Some environments contain electrical equipment that can produce electromagnetic interference. This can affect electrical signals travelling through certain copper cables.

Fiber-optic cable is useful in such environments because the information travels as light rather than as an electrical signal.

5. Physical Environment

The location where the media will be installed also matters. A network engineer may need to consider buildings, underground routes, outdoor installations, electrical equipment, and other physical conditions.

6. Reliability

The selected media should provide a stable and reliable connection for the intended network.

7. Installation Requirements

Some media are easier to install than others. The required tools, connectors, skills, and equipment should therefore be considered before making a decision.

A Network Can Use More Than One Media Type

A network does not have to use only one type of media. Different sections of the same network can use different media depending on their requirements.

For example, in a university network, a student's laptop might connect to an access point using Wi-Fi. The access point could then connect to a switch using copper Ethernet, while the switch could use fiber to connect to another building.

One network can combine wireless, copper, and fiber connections.

Key Terms

  • Network media: The pathway used to carry data between network devices.
  • Wireless media: Uses electromagnetic waves to transmit data.
  • Copper media: Uses electrical signals to transmit data.
  • Fiber-optic media: Uses pulses of light to transmit data.
  • EMI: Electromagnetic interference that can interfere with electrical signals.
  • Bandwidth: The capacity of a communication link to carry data.

Summary

Network media provides the pathway through which data travels between network devices. The three major types are wireless, copper, and fiber-optic media.

Wireless media uses electromagnetic waves, copper uses electrical signals, and fiber-optic media uses light.

When selecting network media, network engineers consider factors such as distance, bandwidth, cost, physical environment, interference, reliability, and installation requirements.

Wireless = electromagnetic waves

Copper = electrical signals

Fiber = light
