Mobile Connectivity

Module 3: Wireless and Mobile Networks

Introduction

Mobile connectivity refers to the different ways a mobile device can connect to networks and communicate with other devices or online services.

A smartphone can connect through Wi-Fi, mobile data, Bluetooth, NFC, and other wireless technologies. Each technology is designed for a different purpose.

Common Ways a Mobile Device Connects

Wi-Fi

Connects a mobile device to a local wireless network, usually through a router or access point.

Mobile Data

Connects a mobile device to the internet through a cellular network such as 4G or 5G.

Bluetooth

Connects nearby devices such as phones, speakers, keyboards, watches, and wireless earphones.

NFC

Allows compatible devices to communicate over a very short distance.

Wi-Fi Connectivity

When a phone connects to Wi-Fi, it communicates wirelessly with a wireless router or access point.

The router normally connects to an internet service provider, allowing devices on the local network to access the internet.

Mobile Data Connectivity

Mobile data allows a phone to access internet services through a cellular network. It does not require the phone to be connected to a Wi-Fi router.

When mobile data is enabled, the phone communicates with a nearby cellular base station. The mobile operator's network then provides connectivity to internet services.

Mobile Device

The phone sends and receives data using its cellular connection.

↓

Cellular Base Station

↓

↓

Internet

The connection reaches websites and online services.

Wi-Fi and Mobile Data Together

A smartphone may have both Wi-Fi and mobile data enabled at the same time. The operating system manages the available network connections and normally uses Wi-Fi when it has a usable Wi-Fi connection.

If the Wi-Fi connection becomes unavailable, the phone may use mobile data instead, depending on the device settings and network conditions.

Some phones also have features that can automatically switch to mobile data when the connected Wi-Fi network has poor internet connectivity.

What is a VPN?

VPN stands for Virtual Private Network. A VPN creates a protected connection between a device and a VPN server over an existing network such as Wi-Fi or mobile data.

A VPN does not replace Wi-Fi or mobile data. Instead, it uses an existing internet connection to establish an additional protected connection.

How VPN Connectivity Works

Without a VPN, your device communicates with online services through the network connection it is currently using.

With a VPN, the device first establishes a connection to a VPN server. Network traffic can then travel through the VPN tunnel before reaching its destination.

Your Device

The phone creates a connection to the VPN service.

↓

VPN Tunnel

Traffic is protected according to the VPN protocol and configuration.

↓

VPN Server

The VPN server receives and forwards traffic toward the destination.

↓

Internet Service

The traffic reaches the requested website or service.

VPN and Encryption

Encryption is the process of transforming readable information into a form that is difficult for unauthorized people to understand.

VPN technologies can use encryption to protect traffic as it travels between the device and the VPN server.

It is important to remember that a VPN does not automatically make everything on the internet completely secure. The security provided depends on the VPN technology, configuration, and services being used.

Plain Text and Encrypted Text

Plain text is information in a readable form. For example, a message before encryption can be understood directly by a person.

Encrypted text, sometimes called ciphertext, is information that has been transformed using an encryption process.

Secure Connections

Encryption is also commonly used by websites and applications to protect information sent over networks.

For example, HTTPS uses encryption to help protect data exchanged between a web browser and a website.

This means that even when you are using Wi-Fi or mobile data, the security of the particular application or service also matters.

Wi-Fi vs Mobile Data vs VPN

Technology Purpose Example
Wi-Fi Connects a device to a local wireless network Connecting a phone to home Wi-Fi
Mobile Data Provides internet access through a cellular network Using 4G or 5G away from Wi-Fi
VPN Creates a protected connection over an existing network Connecting to a VPN server while using Wi-Fi

Key Idea

Wi-Fi and mobile data are methods of connecting a mobile device to a network. A VPN is different because it creates an additional protected connection over an existing network.

Understanding this difference is important. A VPN does not replace your internet connection. Your phone still needs Wi-Fi or mobile data, for example, before it can establish a VPN connection over the internet.
