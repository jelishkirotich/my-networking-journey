Mobile Wi-Fi Configuration

Module 3: Wireless and Mobile Networks

Introduction

Mobile devices such as smartphones and tablets can connect to wireless networks using Wi-Fi. A Wi-Fi connection allows a device to communicate with other devices on a local network and, when the network has internet access, communicate with online services.

To connect a phone to Wi-Fi, we need to understand concepts such as the SSID, Wi-Fi password, router, access point, IP address, and DHCP.

What is an SSID?

SSID stands for Service Set Identifier. It is the name used to identify a Wi-Fi network.

When you open Wi-Fi settings on your phone, you will normally see a list of available wireless network names. These names are SSIDs.

Example

  • Home_WiFi
  • Campus_Network
  • Office_WiFi
  • Guest_Network

What is a Router?

A router is a networking device that connects different networks and forwards packets between them.

A typical home router can also provide wireless connectivity through a built-in wireless access point. This allows phones, laptops, tablets, and other devices to connect to the local network using Wi-Fi.

The router may also provide services such as DHCP, which automatically gives connected devices IP configuration.

What Happens After Connecting?

Connecting to Wi-Fi is not simply about making the phone communicate with the router. The phone also needs network configuration so that it can communicate using IP.

In many home and school networks, this configuration is provided automatically using DHCP.

DHCP

DHCP stands for Dynamic Host Configuration Protocol. It automatically provides network configuration to devices joining a network.

A DHCP server can provide information such as:

  • IP address
  • Subnet mask
  • Default gateway
  • DNS server information

On a typical home network, the router commonly performs the role of the DHCP server.

Static IP vs DHCP

Method How It Works Common Use
DHCP Network configuration is assigned automatically. Phones, laptops, tablets, and most home devices.
Static IP Network configuration is manually assigned. Some servers, network devices, and specialized systems.

Router and SSID

A wireless router can broadcast one or more SSIDs. When a phone scans for Wi-Fi networks, it detects wireless networks that are being advertised in its surroundings.

The SSID identifies the wireless network. The router's configuration determines how that wireless network is provided, including its security settings.

Wi-Fi Password

A secured Wi-Fi network normally requires authentication before a device is allowed to join.

On a personal Wi-Fi network, this is commonly done using a shared password. The router and the device use the configured wireless security protocol to establish the connection.

Modern routers commonly support WPA2 or WPA3 security. WPA3 is the newer standard, while WPA2 remains widely deployed.

Wi-Fi and Mobile Data

A phone can have both Wi-Fi and mobile data capabilities. These are two different methods of obtaining network connectivity.

Practical Example

Imagine that you are at home using your phone.

You open Wi-Fi settings and select your home network, "Jelimo_Home". You enter the correct password and your phone connects to the router.

The router authenticates the connection according to its configured Wi-Fi security settings. DHCP then provides the phone with an IP address and other network configuration.

Your phone can now communicate with devices on the local network and, if the router has internet connectivity, access websites and online services.

Key Idea

Connecting a mobile device to Wi-Fi involves several parts. The SSID identifies the wireless network, the security configuration controls access, the router provides the wireless connection, and DHCP can automatically provide the IP configuration required by the device.

Once these pieces work together, the phone can communicate on the local network and access the internet through the router.
