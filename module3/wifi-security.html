Wi-Fi Security

Module 3: Wireless and Mobile Networks

Introduction

Wireless networks use radio signals to communicate with devices. Because these signals travel through the air, wireless networks need security mechanisms to help prevent unauthorized access and protect information.

Wi-Fi security uses technologies such as authentication and encryption to protect wireless communication between devices and the wireless network.

Why Does Wi-Fi Need Security?

A wired connection requires a physical connection to the network. Wireless communication is different because devices communicate through radio waves.

Without appropriate security, an unauthorized device could potentially attempt to connect to a wireless network.

Wi-Fi security helps control who can connect to the network and helps protect data being transmitted over the wireless connection.

What is Authentication?

Authentication is the process of verifying the identity of a device or user before allowing access to a network.

When you connect your phone to a password-protected Wi-Fi network, you normally provide the network password. The wireless security system uses this information as part of the process of establishing access to the network.

In simple terms, authentication helps answer the question:

"Are you allowed to connect to this network?"

What is Encryption?

Encryption transforms readable information into a protected form so that someone who does not have the required information to decrypt it cannot easily understand the original data.

The readable information is often called plaintext. The transformed information is called ciphertext.

Plaintext

This is the original readable information.

Encryption

An encryption algorithm transforms the information.

Ciphertext

The resulting information is not directly readable as the original message.

WEP

WEP stands for Wired Equivalent Privacy. It was an early security standard for Wi-Fi networks.

WEP is now considered insecure because weaknesses were discovered in its security design. Modern networks should not rely on WEP for protection.

WPA

WPA stands for Wi-Fi Protected Access. It was introduced as an improvement over WEP.

WPA provided stronger security mechanisms and addressed important weaknesses associated with WEP.

WPA2

WPA2 stands for Wi-Fi Protected Access 2. It became widely used for securing wireless networks and provided stronger protection than the older WEP and WPA standards.

WPA2 commonly uses the AES encryption standard to protect wireless communication.

WPA2-Personal

WPA2-Personal is commonly used in homes and small networks. Users normally connect using a shared Wi-Fi password.

WPA2-Enterprise

WPA2-Enterprise is designed for organizations that need stronger access control. Instead of relying on one shared password for everyone, it can use an authentication server to authenticate individual users or devices.

WPA3

WPA3 is a newer Wi-Fi security standard designed to provide improvements over WPA2.

WPA3 includes stronger protections for certain authentication scenarios and provides improved security for modern wireless networks.

The exact security features available depend on the WPA3 mode and the devices being used.

Standard Security Level Current Use
WEP Weak Obsolete

What Happens When You Connect to Wi-Fi?

Connecting to a secured Wi-Fi network involves more than simply typing a password. The device and the wireless network perform authentication and establish the information needed to protect the communication.

1. Select the Network

Your phone displays available wireless networks, identified by their SSIDs.

2. Enter the Password

You provide the credentials required to access the secured network.

↓

3. Authentication

The device and network establish that the connection can be authorized.

4. Secure Communication

The connection uses the security mechanisms provided by the selected Wi-Fi security standard.

SSID

SSID stands for Service Set Identifier. It is the name used to identify a Wi-Fi network.

For example, when you open the Wi-Fi settings on your phone, you might see networks with names such as:

  • Home_WiFi
  • University_WiFi
  • Office_Network

These names are SSIDs. An SSID identifies the wireless network, but it is not the same thing as the Wi-Fi password.

Wi-Fi Password vs Encryption

A common misunderstanding is that the Wi-Fi password itself is the encryption. They are not the same thing.

The password is used as part of the authentication and key establishment process. The wireless security protocol then uses cryptographic mechanisms to protect the communication.

Therefore:

  • SSID: Identifies the wireless network.
  • Password: Helps authenticate access to the network.
  • Encryption: Protects data so that it is not transmitted as ordinary readable information.

Wireless Security in Everyday Life

When you connect your phone to your home Wi-Fi, you may see something such as "WPA2" or "WPA3" in the network's security information.

This tells you which wireless security standard the network is using. Your phone and the router use compatible security mechanisms to establish the wireless connection.

Key Idea

Wi-Fi security has several parts. Authentication controls access to the network, while encryption helps protect information transmitted over the wireless connection.

WEP is an obsolete security standard. WPA improved on WEP, WPA2 became widely deployed, and WPA3 introduced newer security improvements.

Understanding SSIDs, passwords, authentication, and encryption gives you the foundation needed to understand how a secured wireless network works.
