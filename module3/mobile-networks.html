Mobile Networks

Module 3: Wireless and Mobile Networks

Introduction

A mobile network is a wireless communication network that allows mobile devices such as smartphones and tablets to communicate with other devices and access services such as voice calls, text messages, and the internet.

Unlike a home Wi-Fi network, a mobile network is operated by a mobile network provider and is made up of many interconnected cellular sites or base stations.

How a Mobile Network Works

When you use mobile data on your phone, your phone communicates wirelessly with a nearby cellular base station. The base station connects your device to the operator's network, which can then provide access to other networks and the internet.

1. Mobile Device

Your smartphone connects to the mobile network using its cellular radio.

↓

2. Cell Tower

The phone communicates with a nearby cellular base station.

↓

3. Mobile Operator Network

The cellular network manages the connection and routes the communication.

↓

4. Internet or Other Network

The connection can reach websites, online services, applications, and other networks.

What is a Cell?

A cellular network divides a large geographical area into smaller areas called cells. Each cell is served by a cellular base station.

As a person moves from one area to another, the mobile network can transfer the connection from one cell to another. This process allows a user to continue communicating while moving.

Cell Towers and Base Stations

The term "cell tower" is commonly used to describe the structures that hold antennas used for cellular communication. More precisely, the equipment providing cellular service is part of a base station or cell site.

The antennas transmit and receive radio signals between mobile devices and the cellular network.

What a Base Station Does

  • Communicates with mobile devices
  • Transmits and receives radio signals
  • Provides coverage for a particular area
  • Connects mobile devices to the operator's network
  • Supports communication as users move between cells

Generations of Mobile Networks

Mobile networks have developed through several generations. Each generation introduced improvements in communication, data speeds, capacity, and other capabilities.

Generation Main Development Common Uses
1G Analog cellular communication Voice calls
2G Digital cellular communication Voice calls and SMS
3G Improved mobile data Internet access and multimedia
4G High-speed mobile broadband Streaming, browsing, apps, and online services
5G Higher capacity, higher speeds, and lower latency Advanced mobile services and connected devices

SIM Cards and Mobile Networks

A SIM card contains information that allows a mobile network to identify and authenticate a subscriber. Modern phones may also use an eSIM, which performs the subscriber identity function electronically rather than through a removable physical card.

The SIM or eSIM does not itself create the mobile signal. Instead, it helps the mobile operator identify the subscriber and authorize access to network services.

Mobile Data

Mobile data allows a phone to access internet services through a cellular network instead of connecting to Wi-Fi.

For example, when Wi-Fi is turned off and mobile data is enabled, your phone can use the cellular network to access websites, send messages through internet applications, stream content, and use other online services.

Wi-Fi vs Mobile Data

Feature Wi-Fi Mobile Data
Connection Wireless local network Cellular network
Usually provided by Router or access point Mobile network operator
Coverage Usually limited to the local network Can cover large geographical areas
Example Connecting to home Wi-Fi Using 4G or 5G while away from Wi-Fi

Roaming

Roaming occurs when a mobile device uses a network outside the area or network where its normal mobile service is provided.

For example, when traveling to another country, your mobile operator may allow your phone to connect to a partner operator's network. This allows you to continue using supported mobile services while away from your usual network.

Key Idea

A mobile network is much larger than a single Wi-Fi network. It consists of many cells, base stations, network equipment, and connections that work together to provide mobile communication and internet access.

Your phone connects to a nearby cellular site, the site connects to the mobile operator's network, and the operator's network provides access to the required service or destination.
